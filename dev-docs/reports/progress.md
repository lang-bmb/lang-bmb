# BMB 진행 리포트

> 한 파일을 제자리에서 갱신한다. 지난 판은 git 이력에 있다(`git log -p --follow dev-docs/reports/progress.md`). 2026-10-28 판은 이 파일의 이전 이름 `2026-10-28-progress.md`다.
>
> **갱신 방법.** `python3 scripts/progress.py --write dev-docs/reports/progress.md`가 §6 표를 다시 만들고, "지난 보고" 열을 이 파일의 직전 커밋 판에서 채운다. 표의 값은 모두 저장소 파일에서 읽는다(출처 열). §0~§5의 해설과 §7~§9는 표를 보고 손으로 쓴다. 표에 없는 값을 해설에 쓸 때는 출처를 같이 적는다.
>
> **주기.** 주 1회와 국면이 닫힐 때. 국면이 닫힐 때는 종료 감사(`dev-docs/health/<국면>.md`)를 함께 낸다.
>
> **health 값의 뜻.** health 지표는 마지막 `health.py accept` 때의 기준선 값이다. 게이트가 매 커밋 현재 값이 래칫 안에 있는지 확인하므로, 고정 규칙과 래칫 지표는 현재 값과 같거나 더 나쁘지 않다. 예산 지표(V4·V8·V10·V11·B1)는 현재 값이 기준선보다 최대 +10%(B1은 +5%)까지 높을 수 있다. 정확한 현재 값은 `python3 scripts/health.py table`로 본다.

## 1. 부트스트랩

- **사다리.** L1을 충족한다: Rust API에 묶인 통합 시험 파일이 25개에서 1개로 줄었다(S5, 4A-04). 외부 크레이트 0, 외부 프로세스 {clang, z3}, 생성 바이너리는 libc만(S1~S3).
- **포팅 준비.** ③ 런타임·시스템 인터페이스(4C, 감사 `dev-docs/health/4C.md`)와 ④ 표준 라이브러리(4B, 감사 `dev-docs/health/4B.md`)가 닫혔다. stage0의 맵이 쓰는 텍스트 키(`BTreeMap<String, V>`, 4B-04)와 인턴 표·JSON도 섰다. 남은 선행 조건은 ⑤ 문법 결정과 stage0 동결(4D-01)이다.
- **해석.** S4가 42,712 → 49,071로 늘었다. 4D(동결)부터 S4에 +2% 예산이 붙으므로 동결 전의 언어 변경(⑤)이 포팅량을 정한다.

## 2. 언어 개발 수준

- **국면.** M2-d(표현 확장)가 통과했다: `proof fn`, 2U 문자열과 JSON(JSONTestSuite `y_`·`n_` 283/283), `f64`(F6 변이체 셋을 게이트 전체가 잡음), n-body·spectral-norm, 메서드 구문.
- **증명 게이트의 신뢰.** 표준 라이브러리를 쓰면서 검증기 결함 셋을 찾아 고쳤다: `String` 길이가 피호출자·루프 뒤에 남음(1B-55), 루프 안 `push_str`가 하보크되지 않음(1B-56의 퍼저가 찾음), `proof fn` 매개변수의 `Vec<String>` 사실이 잘못된 정렬(E0812). 셋 다 기대던 증명은 없었다. 미증명 정의 0(V3), 판정 흔들림 0.02%(V7, `json::add` 하나).
- **비용 지표.** V12가 297 → 208로 줄었다. V4·V10이 는 것은 새 프로그램과 표준 단위(`json` 3.5M)다.
- **쓰기 표면.** `bmb fix`의 적용기가 정규형을 지키게 고쳤고(`mut`·`pub` 128/128 원문으로), E0511(트리거 없음)에 기계 수정을 더했다(변수 하나인 정량자 156개 중 137개가 원문과 같은 자리). P3 0.8868 → 0.9118.

## 4. 생태계

- **닫혀 있다.** 5E는 원칙 4·6이 측정으로 입증된 뒤에 연다(§5).
- **쌓인 것.** 증명된 표준 라이브러리 11단위 4,301줄(의무마다 100만 이하, 시드 8개 불안정 0), CLI 명령 22개, MCP 도구 7+5.

## 5. 미션 효용

- **가설.** 같음(확정 0, 반증 2, 결정론 근거 7, 파일럿 5, 측정 중 1, 미측정 11). 이번 주기에 새 모델 실행은 없었다.
