# ADR-0012: rustc 없는 독자 컴파일러, LLVM 직접

- 상태: 채택
- 날짜: 2026-10-24
- 관련: DESIGN.md §1, 원칙 9, genesis Q10

## 맥락
BMB는 Rust 방언이다. 어디까지 직접 구현할 것인가.

## 결정
파서부터 LLVM IR 생성까지 **완전 독자 구현**한다. rustc에 의존하지 않는다. 외부 의존은 Z3와 LLVM이다.

## 근거
검토한 대안:

| 안 | 판정 |
| --- | --- |
| Verus 위에 얹고 BMB는 린트·도구로 | 기각: 독자성 부족 |
| rustc 드라이버(파서·타입·빌림 검사 재사용) | 기각: nightly 내부 API 추종 비용, 문법 확장 제약 |
| 독자 프론트엔드 + Rust 출력 후 rustc 빌드 | 기각: rustc 의존 |
| **완전 독자(LLVM 직접)** | **채택**: 증명을 최적화에 직접 연결(원칙 9) |

## 결과
- 컴파일러 구현 범위가 크다(v0: 144K줄). 완화: 2차 참조로 빌림 검사기 축소(ADR-0015), 컴파일러·백엔드 각 하나, 최소 관통 경로부터(ADR-0016).
- 셀프호스팅은 의미론이 안정된 뒤에 결정한다.
