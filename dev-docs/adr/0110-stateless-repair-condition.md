# ADR-0110: 상태 없는 수리 차례: 매 요청이 새 대화인 측정 조건

- 상태: 채택(자율 채택, AUTONOMY §4 "결정 기록": ADR-0070의 새 측정 조건 하나. 실행은 증거 단계 뒤 T0-37. 아홉째 실행 계획, 사람 승인 "권장안 채택")
- 날짜: 2026-11-10
- 관련: ADR-0070(측정 조건), ADR-0068·0071(모델이 보는 것을 줄이는 판), ADR-0103(검정력, 주장의 기준 모델), ADR-0093(캐시), 백로그 T0-36·T0-37

## 맥락

- 지금의 에이전트(`model_api.OpenAIAgent`, `anthropic_agent.AnthropicAgent`)는 매 요청에 이력 전체를 다시 보낸다. 그래서 세션의 입력 토큰은 왕복 수의 제곱에 가깝게 는다.
  - 예: sonnet `brb-write`의 `t14-dedup-sorted`는 요청당 입력이 2,749 → 56,096토큰으로 늘었다. 세션에서 새로 생긴 텍스트는 83KB인데 입력 토큰 합은 883,748이다(AI 사용자 의견서 2026-11-10 §3.3).
- BMB에서 상태는 작업 공간(도구 뒤)에 있다. 이력은 그 상태를 되풀이한다.
- 상한 추정(부록 A 공식, 요청·호출 1:1 가정, 24세션 중 4개 어긋남): 왕복 수와 출력이 같다면 sonnet `brb-write`의 총 토큰은 2,188,065 → 749,725(0.34배)다. 이력을 잃은 모델이 같은 시도를 되풀이할 위험은 넣지 않은 값이다.

## 결정

1. **요청의 내용.** 매 요청은 시스템 프롬프트와 사용자 메시지 하나다. 사용자 메시지는 이 순서다.
   1. 과제 문장
   2. `## State now`: 지금 상태
   3. `## Attempts so far`: 세션의 도구 호출마다 한 줄(`N. tool: ok|error: 결과 첫 줄`, 160바이트까지)
   4. `## Results of your last calls`: 직전 차례의 도구 결과 전부
   - 이전 차례의 응답과 도구 결과는 다시 보내지 않는다.
2. **두 팔에 같은 규칙.** `State now`는 BMB 팔에서는 작업 공간 파일(정규형)이고, Rust 팔에서는 크레이트의 소스 파일이다. 도구, 호출 한도, 판정은 원판 그대로다.
3. **프롬프트는 바꾸지 않는다.** 이력이 없다는 안내를 더하지 않는다. 메시지 하나가 스스로 완결된다.
4. **구현과 적용 시점.**
   - 구현은 `bench/m1/stateless.py`의 `Stateless`다. 공급자 에이전트를 감싸고, 결과 행과 세션 기록의 모양을 지킨다. `settings`에는 `"history": "stateless"`가 붙는다.
   - 하네스 연결(집합의 `set.json`에 `"history": "stateless"`)과 동결 판은 T0-37 준비 때 만든다. 지금 하네스를 고치면 증거 단계 중인 측정 세션의 하네스와 어긋나기 때문이다.
   - 이 조건은 오라클(대본) 팔로 확인할 수 없다(대본에는 이력이 없다). 게이트의 근거는 두 공급자의 가짜 모델 시험(`bench/m1/test_stateless.py`)이다.
5. **가설 H-HISTORY(측정 전 등록).** 상태 없는 차례는 성공률을 D(ADR-0077) 넘게 떨어뜨리지 않으면서 성공당 토큰을 줄인다.
   - 비교: `brb-write`·`bvb-write`의 이 판 대 원판. 같은 커밋, Rust 팔도 같은 규칙. sonnet 1회(ADR-0103 결정 3), qwen은 순차 반복.
   - 반증: 성공률이 D를 넘게 떨어지거나, 성공당 토큰의 차이가 D 안이면 반증이다.

## 근거

| 안 | 판정 |
| --- | --- |
| **매 요청 새 대화 + 상태 + 시도 한 줄(채택)** | 정본이 도구 뒤에 있다는 설계를 그대로 쓴다. 두 팔에 같은 규칙을 걸 수 있다 |
| 이력을 최근 N 차례로 자르기 | N이 새 자유 변수가 되고, 상태는 여전히 이력 안에 흩어져 있다 |
| 캐시로 비용만 줄이기(ADR-0093) | 가격은 줄지만 모델이 읽는 양과 토큰 지표(전체 프롬프트)는 그대로다 |
| 하네스에 지금 연결 | 측정 세션이 증거 단계에서 같은 하네스를 쓰고 있다. T0-37 준비로 미룬다 |
