# ADR-0121: 포트는 stage0의 자료 모양을 따른다

- 상태: 제안(2026-11-11). 포팅 지도 §5.2의 "아레나 접근" 대안 선택을 대신한다
- 날짜: 2026-11-11
- 관련: ADR-0037(부트스트랩), ADR-0047(재귀 타입, `Box`), ADR-0113(포팅된 구성 요소의 고정), `dev-docs/measurements/selfhost-port-map.md` §5.2·§7.4, `dev-docs/experiments/port-shape/results.md`, 백로그 4D-02

## 맥락

- 포팅 지도(4A-02)는 포트의 구문 트리를 아레나(`Vec<Node>`와 인덱스)로 가정했고, 그 수량자 불변식을 자기 증명의 가장 큰 위험으로 꼽았다(§5.2, §7.4). 그때는 언어에 `Box`와 재귀 타입이 없었다.
- 지금은 있다(ADR-0047): stage0의 구문 트리(`compiler/src/ast.rs`: `enum`과 `Box`, `Vec`)를 같은 모양으로 쓸 수 있다.
- 두 모양을 같은 작은 파서로 쟀다(`port-shape/results.md`). 둘 다 탈출구 없이 전부 증명됐고 출력이 같다. 증명 비용(`rlimit`)은 아레나가 2.6배, 가장 비싼 의무는 10배, 시드에 따른 비용 폭은 3.09 대 1.01이다. 줄 수와 실행 시간은 같은 수준이다.

## 결정

1. **포트의 자료 구조는 stage0의 것과 같은 모양으로 쓴다.** stage0이 소유 트리(`enum`, `Box`, `Vec`)인 곳은 소유 트리로, stage0이 표와 인덱스인 곳은 표와 인덱스로 쓴다. 구성 요소마다 stage0의 타입 하나에 포트의 타입 하나가 대응한다.
2. **인덱스 구조의 불변식은 "가리키는 쪽이 뒤"다.** stage0이 인덱스를 쓰는 곳(표, 인턴, 맵의 정렬 배열)에서는 원소가 자기보다 앞의 원소만 가리킨다는 단조성 하나를 타입 불변식으로 쓴다. 검사하는 접근 함수나 탈출구로 감싸지 않는다.
3. **모양을 바꾸는 것은 측정이 요구할 때다.** 포팅 원장(ADR-0122)에서 그 구성 요소의 증명 비용이나 실행 시간이 관문의 기준을 넘으면, 그 구성 요소의 모양 변경을 stage0과 포트 양쪽에 함께 한다(고정 전이면 stage0을 먼저 바꾼다, ADR-0113 결정 3).
4. **깊이는 연료로 묶는다.** 트리를 걷는 재귀는 stage0의 중첩 한도(256)를 연료로 받는다. 측도는 정수 하나다(깊이와 순위를 엮는다).

## 근거

| 안 | 판정 |
| --- | --- |
| **stage0의 모양을 따른다(제안)** | 포팅의 정석은 옮기는 것이지 다시 설계하는 것이 아니다(JUDGMENT S1). 차등 시험이 구성 요소 경계에서 같은 출력을 요구하고, 고정 뒤의 수정은 두 쪽을 한 커밋에서 바꾸므로(ADR-0113) 모양이 같아야 수정이 같은 자리로 간다. 잰 증명 비용도 낮다 |
| 아레나로 다시 설계 | 실험에서 가능했지만 증명 비용 2.6배에 용량 논증이 모든 함수의 계약에 실린다. stage0과 모양이 달라 수정의 대응이 깨진다. 실행 시간 이득(16%)은 관문의 기준(stage0의 2배 이내)에 비해 작다 |
| 구성 요소마다 그때 정한다 | 첫 구성 요소(파서)의 선택이 뒤의 모든 구성 요소(검사기·증명기가 그 트리를 읽는다)를 묶는다. 미리 정해야 한다 |

실험의 한계(한 과제, 340줄, 팔마다 한 세션)는 결과 문서에 있다. 그래서 결정 3을 둔다: 큰 크기에서 다르게 나오면 원장이 보인다.

## 결과

- 포팅 지도 §5.2의 "아레나 인덱스 유효성" 위험은 구문 트리에는 해당하지 않게 된다. 남는 인덱스 구조는 표·인턴·맵이다. 채택되면 §5.2·§5.4·§7.4에 정정 주석을 단다.
- 실험이 드러낸 마찰 둘이 포팅 전에 풀 일로 남는다: 출력 버퍼의 길이 의무(백로그 `4D-13`), 거짓 의무에서 해법기가 메모리로 죽는 실패 꼴(백로그 `T2-16`).
- MCP 서버처럼 오래 도는 경로의 메모리(포팅 지도 §5.1)는 소유 트리에서 요청 단위 해제가 범위 끝의 해제로 주어진다.
