# ADR-0015: 소유·이동 + 2차 참조

- 상태: 채택
- 날짜: 2026-10-24
- 관련: DESIGN.md §5, ADR-0012, genesis Q13

## 맥락
Rust 수준의 빌림 검사기(수명 추론 포함)를 독자 구현하는 비용은 크다. 검증기 쪽에서는 별칭이 프레임 조건을 복잡하게 만든다.

## 결정
메모리 모델은 **소유·이동 + 2차 참조**다. 참조(`&`, `&mut`)는 함수 인자로만 넘길 수 있고, 저장하거나 반환할 수 없다. 표면은 Rust의 `&`·`&mut` 그대로다.

## 근거
- 수명 표기와 수명 추론이 언어에서 사라진다. 독자 빌림 검사기 비용이 줄어든다.
- 별칭이 제한되어 검증기의 프레임 조건이 단순해진다.
- 모든 `&mut`에 noalias를 붙일 수 있다.

## 결과
참조를 담는 구조(반복자, 뷰 등)는 핸들이나 인덱스 방식으로 대체해야 한다. 이 비용은 Rust 습관 오류율로 측정한다.
