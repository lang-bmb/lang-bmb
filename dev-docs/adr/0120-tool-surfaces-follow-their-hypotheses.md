# ADR-0120: 후보 도구 표면은 가설 판정을 따라 정리한다

- 상태: 채택(사람 승인 2026-11-11 "승인, 자율 실행/검증 승인". 백로그 4D-11, ADR-0113·0116의 보완)
- 날짜: 2026-11-11
- 관련: ADR-0073(편집 표면 셋), ADR-0109(일괄 탐침), ADR-0111(조정 가설), ADR-0113(포팅된 구성 요소의 고정), ADR-0116(동결 전 축소 조사), ADR-0100(동결 대상은 받아들이는 언어), `dev-docs/measurements/surface-cut.md`

## 맥락

- 동결 전 축소 조사(4D-11)의 결과: 언어 표면에는 줄일 것이 없다. 채택된 기능은 모두 검증돼 있고, 전용 코드가 있는 기능은 클로저와 상수 항목뿐이다.
- 도구 쪽에는 조정 가설의 후보로 들어온 표면이 셋 있다: JSON 구문 트리 편집(`bmb ast`, MCP `read_ast`·`edit_ast`: `ast_json` 2,397줄), 파일 diff 편집(MCP `edit_file`: `udiff` 252줄), 일괄 탐침(`bmb probe`, MCP `probe`: 339줄). 가설은 H-EDIT와 H-PROBE다.
- 후보 표면은 측정으로 하나를 고르기 위해 넣은 것이다. 고른 뒤에도 남기면 포팅 대상(약 3천 줄)과 유지할 표면이 는다.
- 도구는 동결 대상이 아니다(ADR-0100 결정 1). 그러나 도구가 포팅돼 고정되면 두 쪽을 함께 고쳐야 한다(ADR-0113).

## 결정

1. **언어 표면은 지금 그대로 동결한다.** 축소 조사의 결론이다.
2. **조정 가설의 후보 표면은 판정에 따라 정리한다.** 가설이 판정되면 고르지 않은 표면의 도구와 그 코드를 지운다. H-EDIT의 판정(T1-41)은 편집 표면 셋 중 하나를 남기고, H-PROBE의 판정(T0-37)은 일괄 탐침을 남기거나 지운다.
3. **시한은 도구 포팅 착수 전이다.** 도구의 포팅은 P5 이후이고 관문 B 뒤다(ADR-0111). 그때까지 판정이 없는 후보 표면은 포팅 범위에서 빼고, stage0과 함께 은퇴시킨다(4G). 은퇴 뒤에 다시 필요해지면 BMB 컴파일러 쪽에서 새 결정으로 넣는다.
4. **가설에 걸리지 않은 도구는 대상이 아니다.** `bmb weaken`(계약 조정, H-GAME의 감사, 교환 관계), `lint`, `uses`, `fix`, 맵·질의, 작업 공간은 제품 기능이다.
5. **새 후보 표면을 넣는 ADR은 그 표면을 지우는 조건을 함께 적는다.** 조정 가설을 등록할 때의 규칙(ADR-0111 결정 5)에 더한다.

## 근거

| 안 | 판정 |
| --- | --- |
| **판정에 따라 정리, 시한은 도구 포팅 전(채택)** | 등록한 측정을 버리지 않고, 고르지 않은 표면이 포팅과 고정의 비용을 만들지 않는다 |
| 지금 지운다 | sonnet 자료는 JSON 구문 트리 표면에 불리하지만(`brb-ast` 22/24·691만 토큰 대 `brb-diff` 24/24·272만 토큰) qwen 실행이 남았다. 판정 전에 지우면 사전 등록을 어긴다 |
| 모두 포팅한다 | 후보 셋 중 둘은 고르지 않을 표면이다. 포팅하면 지울 코드를 두 번 쓴다 |
| 클로저 등 언어 기능을 뺀다 | 뺄 이유가 포팅량뿐이다. 작업량은 기준이 아니다(JUDGMENT §5) |

## 결과

- 포팅 지도의 도구 구성 요소(C10·C12) 추정에서 후보 표면 2,988줄은 "판정 뒤 확정"으로 둔다.
- `T1-41`과 `T0-37`의 완료 기준에 "고르지 않은 표면의 제거 태스크 도출"이 더해진다.
- 동결 선언(4D-01)의 전제 가운데 축소 조사(ADR-0116 결정 1)가 닫힌다.
