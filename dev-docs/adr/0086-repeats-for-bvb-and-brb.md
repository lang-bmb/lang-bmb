# ADR-0086: BVB·BRB 반복 측정과 집합별 최소 차이

- 상태: 채택 (사람 승인 2026-11-04 "권장안 승인": 측정 판정력 ADR 착수, T0-13 표면 결정은 이 결과 뒤로). ADR-0077 §2(반복 범위)를 넓히고 §4(최소 차이)를 보완한다
- 날짜: 2026-11-04
- 관련: ADR-0066 §3·§5, ADR-0077, 백로그 T0-13·T0-14·T0-33·2A-16

## 맥락

- ADR-0077의 최소 차이 D = 30%p는 qwen m1 작성의 반복 범위(6/10~9/10)에서 나왔고, 반복이 없는 모든 집합의 단일 실행 비교에 쓰인다.
- 2026-11-04까지의 비교 대부분이 D 안이라 방향을 주장하지 못했다. T0-13 여섯 칸 중 다섯, T0-14 둘 다다. m1은 과제 10개라 한 과제가 10%p다. 과제 45개(BVB)·24개(BRB)인 집합의 흔들림은 잰 적이 없다.
- sonnet은 BVB·BRB에서 천장에 닿는다(45/45, 24/24). 그래서 표면·변형의 차이를 가르는 것은 주로 qwen이다.

## 결정

1. **반복 범위.** `openai:qwen3.8-27b`로 BVB와 BRB(BMB 팔)를 원판·쓰기 표면 각각 **5회** 반복한다(`run_models.REPEAT_SETS`에 `bvb`·`brb-bmb`·`bvb-write`·`brb-write`). 첫 반복은 T0-13과 같은 커밋 `e5247e8d`에서 한다. 순서는 쓰기 표면(`bvb-write`·`brb-write`)이 먼저다. T1-41·T0-17·T0-15가 그 판과 비교하기 때문이다. 실행·보고 규칙은 ADR-0077 §1과 같다(고르거나 버리지 않음, 모두 커밋). BRB Rust 팔은 반복하지 않는다(sonnet·qwen 모두 24/24).
2. **집합별 최소 차이.** 반복이 있는 집합 X의 D(X)는 X 작성 성공률의 반복 범위를 퍼센트포인트로 올림한 값이다(`repeat.py`의 "집합별 최소 차이" 줄). 두 판 X·Y(예: 원판과 쓰기 표면, 원판과 변형 판)의 단일 실행 비교는 max(D(X), D(Y))로 읽는다. 둘 중 반복이 없는 판이 있으면 ADR-0077 §4의 전역 D를 쓴다. 집합마다 과제 수와 흔들림이 다르므로 한 집합의 범위를 다른 집합에 옮기지 않는다.
3. **기존 판정의 재독.** 반복 결과가 나오면 T0-13(쓰기 표면, 표면 결정)과 T0-14(H-NAME)의 차이를 이 규칙으로 다시 읽어 보고서에 덧붙인다. 원래 판정 줄은 지우지 않는다.
4. **미션 목표값(2A-16).** BVB 작성 목표값을 이 반복의 구간으로 함께 판정할 수 있게 2A-16을 이 결과 뒤에 정한다.

## 근거

- m1의 범위로 정한 D가 과제 수가 4.5배인 BVB에 그대로 쓰이는 것은 판정력을 잃는 쪽으로 틀린다. 한 과제 몫이 2.2%p라 흔들림의 범위도 다를 것이다. 재 보지 않으면 모른다.
- qwen은 반복 비용이 없다(ADR-0066 §2, 게이트웨이의 로컬 장비). 시간은 qwen 세션당 약 8분이다. BVB 판 하나 5회는 병렬 4로 약 8시간, BRB는 BRB 판정의 벽시계 한도 때문에 병렬 1로 약 16시간이다.
- **기각한 것:** (가) 전역 D를 그대로. 판정력이 없어 측정 줄을 더 돌려도 "판정 불가"가 쌓인다. (나) sonnet도 반복. 천장이라 흔들림을 재지 못하고 유료다(ADR-0077 (나)와 같은 이유). (다) 과제 단위 이항 모형으로 D를 계산. 같은 과제의 시행이 독립이 아니어서(ADR-0077 근거) 실행 수준의 범위를 잰다.

## 결과

- 코드: `bench/run_models.py`의 `REPEAT_SETS`, `bench/repeat.py`(BRB 행은 작성으로 세고 집합 이름에 팔을 붙임, 집합별 최소 차이 줄).
- 시험: `bench/test_run_models.py`의 `test_repeats_are_declared_for_qwen_on_m1_and_m1b`, `bench/test_repeat.py`의 `test_brb_rows_are_writes_of_their_arm`.
- 첫 실행은 `e5247e8d`의 측정 체크아웃에서 하네스를 직접 부른다(그 커밋의 `run_models.py`는 반복을 m1·m1b에만 허용한다). 결과 머리의 `repeat`는 하네스의 `condition_fields`가 `BMB_REPEAT`에서 기록한다. 그 커밋의 BRB 하네스도 같은 함수를 쓴다.
- 되돌리기: `REPEAT_SETS`를 ADR-0077의 둘로 되돌리고 집합별 줄을 지운다.
