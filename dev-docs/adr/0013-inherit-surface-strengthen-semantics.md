# ADR-0013: 표면은 승계, 발전은 편의 포기에서

- 상태: 채택
- 날짜: 2026-10-24
- 관련: DESIGN.md §4, genesis Q11

## 맥락
Rust·Verus 표면을 왜 승계하는가. 그리고 BMB가 그들보다 "발전된" 것이라고 말할 근거는 무엇인가.

## 결정
- 표면 승계의 주목적은 **LLM 유추 가능성**이다. 학습하지 않은 언어를 기존 지식으로 쓰게 한다.
- 발전의 원천은 Rust·Verus가 **인간 편의로 남긴 것을 포기**하고, 그 대가를 회수하는 데 있다.
- 형태 규칙: 새 구문보다 "선택을 필수로". 새 구문은 Rust 대응물이 없을 때만(효과, 근거, 증명 문맥).

## 근거
학습 데이터가 적은 언어에서 LLM 성능은 24~39%p 낮다(genesis §4). 표면을 승계하면 이 손실을 줄인다. 독자 문법은 v0에서 폐기 대상이었다.

## 결과
- 유효한 BMB 코드는 "더 장황한 Rust"처럼 보여야 한다.
- Rust 습관 오류율을 측정하고, 회수보다 유추 손실이 큰 엄격화는 되돌린다(DESIGN.md §4.1).
