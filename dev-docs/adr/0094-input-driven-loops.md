# ADR-0094: 입력이 끝날 때까지 도는 루프

- 상태: 채택 (2026-11-06, 사람 승인 "미증명 표식 남기고 진행". 백로그 4C-04)
- 날짜: 2026-11-06
- 관련: ADR-0016(루프·재귀 `decreases` 필수), ADR-0030(효과 `nondet`, 테스트 필요 면적 §4), ADR-0049(`loop`), ADR-0091(시스템 인터페이스), 포팅 지도 P11(MCP 서버)

## 맥락

- 4C-02 (a)가 표준 입력을 들였다. 끝까지 읽는 줄 루프(`loop { match std::io::read_line(&mut l) { Ok(0) => break, .. } }`)는 종료가 바깥 입력에 달려 측도가 없다. ADR-0016은 모든 루프에 `decreases`를 요구해 E0506으로 막혔다.
- 셀프호스팅에서 이 꼴이 필요하다: MCP 서버의 요청 루프(P11), 줄 단위 도구. 지금은 입력을 전부 읽고 바이트를 돌거나 줄 수에 한도를 두어야 했다(`tests/tools/wc.bmb`).
- Verus는 실행 코드의 루프에 종료 증명을 요구하지 않는다(명세·증명 코드에만). Rust에는 종료 개념이 없다.

## 결정

1. **`nondet` 정의의 `loop`는 `decreases`를 생략할 수 있다.** 선언 효과에 `nondet`이 있는 실행 함수 안의 `loop`(문 `while`·`for`는 아니다)만이다. 다른 곳은 E0506 그대로이고, `loop`의 E0506 안내가 이 길을 알린다.
2. **부분 정확성으로 증명한다.** 그 루프의 불변식·의무·사후 조건은 그대로 증명하고, 측도 의무만 없다(종료하면 맞다).
3. **표식을 남긴다.** 그런 루프를 가진 정의와 그것을 (전이적으로) 부르는 정의는 L1·`status` 행에 `"termination":"unproved"`가 붙고(키는 해당할 때만, ADR-0020 §1), `test_reasons`에 `nonterminating`이 든다(ADR-0030 §4의 테스트 필요 면적). LLVM `willreturn`·`mustprogress`는 이런 정의에 붙지 않는다(ADR-0084의 2F-04가 다룰 때의 조건).

## 근거(검토한 대안)

| 안 | 판정 |
| --- | --- |
| **`nondet` 정의의 `loop`만 측도 생략 + 표식(채택)** | 종료가 정말 바깥에 달린 곳(입력을 읽는 정의)에만 열린다. 증명은 부분 정확성으로 남고, 미증명 면적이 맵에 보인다 |
| 규칙 유지(전부 읽고 돌기, 줄 수 한도) | 서버 루프(P11)를 쓸 수 없다. 한도는 임의 값이고 거짓 종료를 만든다 |
| 연료 인자(`fuel: u64`) | 정의마다 의미 없는 인자가 붙고, 연료가 다하면 무엇을 할지가 또 정해야 할 동작이다 |
| 모든 실행 루프에서 측도 선택 | 전함수 보장(DESIGN.md §4.1)을 잃는다. 바깥 입력과 무관한 루프까지 증명이 약해진다 |

## 결과

- `std::io::read_line`으로 끝까지 읽는 루프를 쓸 수 있다. 시험 `compiler/tests/system.rs`의 `input_loops_run_until_the_end`.
- 맵·`status`·`tests`가 종료 미증명 정의를 센다. 자기 증명(4F)의 미증명 면적에 이 정의들이 든다.
