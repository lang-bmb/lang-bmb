# ADR-0011: 저장 형식은 텍스트, 배치는 도구가

- 상태: 채택
- 날짜: 2026-10-24
- 관련: DESIGN.md 원칙 1·7, genesis R1

## 맥락
에이전트가 도구로만 접근한다면 코드가 텍스트 파일이어야 할 이유가 있는가(구조화 DB 등 대안).

## 결정
쟁점을 종결한다. 저장 형식 자체는 중요하지 않다. **텍스트로 두고, 파일 배치는 도구가 결정론적으로 정한다.**

## 근거
에이전트가 도구로만 접근하므로 저장은 도구 뒤에 숨는다. 텍스트는 git·diff 같은 기존 인프라를 그대로 쓸 수 있다.

## 결과
- 파일 경로는 의미를 갖지 않는다. 모듈 정체성은 선언된 구성 단위다(v0의 "파일 경로 = 모듈" 폐기).
- 같은 코드면 같은 파일 배치가 나와야 한다(정규형 출력).
