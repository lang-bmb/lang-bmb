# ADR-0068: 압축 에이전트 투영(`bmb mcp --compact`)

- 상태: 채택 (자율 채택, AUTONOMY.md §4: MCP 서버의 선택 플래그. 기본 출력, 맵 스키마, 동결 집합은 그대로). 기본값 전환은 §5의 측정 뒤 사람 승인 안건
- 날짜: 2026-10-30
- 관련: DESIGN.md 원칙 6·7, §7.2, ADR-0019 §2(맵의 12자 해시), ADR-0020(맵 스키마), ADR-0021(동결), ADR-0066(qwen 64K), 백로그 2D-23·2D-25·T1-05·T0-15

## 맥락

- 차례당 문맥(2D-25, `dev-docs/experiments/context-size/`): 큰 작업 공간(m1b)에서 마지막 요청 문맥의 63%가 읽기 결과다. `query units`(L0 전체)와 `map L1`(정규형 코드의 3.1배) 같은 덤프가 행마다 64자리 해시 셋, 파일·줄, 증명 비용, 빈 필드를 싣는다. 모든 작성 세션에서 `write`·`verify`는 성공한 정의까지 작업 공간 전체의 상태 줄을 돌려준다.
- 정식 qwen 측정(ADR-0066)의 문맥은 64K다. m1b에서 요청당 평균이 47,733토큰인 세션이 출력 한도로 끝나 실패했다. 문맥 크기는 비용만이 아니라 성공률 요인이다.
- 에이전트용 L1이 같은 질문에 답하는 코드보다 커서는 안 된다(T1-05, 원칙 7). 지금은 3.1~3.6배다.
- MCP 출력과 도구 설명은 진행 중·예정 측정(T0-10·T0-11·T0-13·T0-14·2A-07)의 동결 조건이라 기본값을 지금 바꿀 수 없다(ADR-0021).

## 결정

1. **투영.** `bmb mcp --compact`는 모든 도구 결과를 `view::compact`에 통과시킨다. 결과 JSONL만으로 계산하는 순수 함수다.
   - 맵 머리 줄은 뺀다.
   - L1 표면: `// 경로: 상태` 한 줄 뒤에 본문 없는 정의의 정규형(속성 줄, 시그니처, 계약 절, ADR-0019 §1의 배치). 상태는 `verified`, `failed F of N obligations`, 의무가 없으면 생략.
   - L0: 단위는 `#[summary("..")] mod 경로;`, 정의는 `종류 경로`.
   - L2: `FROM KIND TO`(필요하면 ` arg N`, ` <타입>`).
   - `slice`: 정의와 의존마다 `// 경로` 뒤의 코드 원문(JSON 이스케이프 없음).
   - 증명 결과(`verify`, `write`, `build`): 진단은 그대로, 성공한 정의의 상태 줄은 `{"verified":N}` 한 줄로, 나머지 상태 줄은 증명 비용을 뺀다.
   - 그 밖의 JSON 행: `level`과 빈 값(빈 배열, `null`, 빈 문자열)을 빼고 해시는 `sha256:` + 12자(ADR-0019 §2).
2. **기본값과 CLI는 그대로다.** 플래그가 없으면 출력·도구 설명·`instructions`가 이전과 같은 바이트다. `bmb map`·`bmb query`·`bmb verify`와 맵 스키마(ADR-0020)는 JSONL 그대로다. 판정·도구는 그쪽을 쓴다.
3. **도구 설명.** 플래그가 있으면 `query`·`map`·`verify`(와 `write`)의 설명이 받게 될 형식을 말한다. 이름과 입력 스키마는 같다.
4. **측정 판은 준비만 한다.** `bench/view/gen.py OUT`이 동결된 `m1b-write`·`bvb-write`에 서버 플래그 `--compact` 하나만 더한 `m1b-write-compact`·`bvb-write-compact`를 만든다(프롬프트·과제·시드·변이체는 같은 바이트). 동결(생성해 MANIFEST와 함께 커밋)은 T0-15가 첫 실행 직전에 한다. 게이트는 생성한 판에서 기준·약한 해법이 통과·거부되는지만 본다(`bench/view/test_gen.py`).
5. **기본값 전환의 조건.** (a) 현재 표면의 측정 T0-10·T0-11·T0-13·T0-14·2A-07이 끝난 뒤, (b) T0-15가 압축 판을 원판(`*-write`)과 같은 커밋에서 qwen으로 돌려(ADR-0066 §3에 따라 sonnet도 같은 커밋), (c) 작성·탐색 1회 성공률과 BSB 판별률이 원판보다 낮지 않고 요청당 프롬프트 토큰이 줄면 기본값을 `--compact`로 바꾸는 ADR을 사람 승인으로 올린다. 바꾼 뒤의 측정은 새 판 이름으로 보고하고 이전 결과와 섞지 않는다(ADR-0021 §1).

## 근거

- **원인 층(JUDGMENT §3):** 해시·위치·비용은 도구(증분 캐시, 중복 찾기, 진단 위치)가 쓰는 맵 필드이고, MCP에는 해시나 위치를 받는 도구가 없다. 에이전트에게 보이는 형식이 원인이므로 도구 층의 투영에서 고친다. 맵 스키마에서 해시를 빼는 것은 도구가 쓰는 정보를 잃게 하는 다른 층의 조치라 택하지 않는다.
- **후보 비교(같은 작업 공간 전체의 표면, 정규형 코드 대비 추정 토큰, 세 시드):** 해시 12자 1.88~2.25, 해시 뺌 1.40~1.68, 위치·비용까지 뺌 0.99~1.21, 빈 필드 생략까지 0.82~1.02, Rust 꼴 0.44~0.59. 추정 오차(−7%~+4%) 밖에서 코드 이하인 것은 Rust 꼴뿐이다(C3·S4).
- **정석(S1):** 시그니처를 소스 꼴로 보이는 것은 rustdoc의 항목 시그니처, IDE 호버, 에이전트 도구의 저장소 지도(Aider repo map: 파일별 정의 줄의 코드 꼴 골격)가 쓰는 방법이다. BMB의 표면이 Rust라는 정의(DESIGN §4)와도 맞다. 본문 없는 정규형은 `bmb fmt`의 배치 규칙을 그대로 쓴다(S3: 새 표기를 만들지 않는다).
- **결정론(C2):** 투영은 결정론적인 JSONL의 순수 함수다. 같은 입력이면 같은 바이트다.
- **증명 결과의 접기:** 성공한 정의의 상태 줄 목록은 작업 공간 크기에 비례하고 다음 행동에 쓰이지 않는다. 실패와 진단은 그대로 두므로 고칠 길(반례, 수정 제안)은 줄지 않는다(HEALTH §5.3).
- **효과(재실행, 파일럿 세션의 같은 호출):** 도구 결과 토큰 −74%~−79%, 마지막 요청 m1b −57%, m1b-write −54%, BVB −9~−12%. qwen m1b 세션의 마지막 요청 하한 최댓값 40,150 → 11,434.

## 결과

- 압축 투영에서 에이전트가 보지 않는 것: 해시(그 밖의 행은 12자), 파일·줄, 증명 비용, 성공한 정의의 의무 수, L0 단위 행의 목록(뒤따르는 정의 줄로 같은 정보). 필요하면 `query status`가 상태별 의무 수를 준다.
- 하네스의 판정(`bmb` CLI의 JSONL)과 지표(`read_bytes`의 바이트 근사)는 그대로다. 압축 판의 "질의당 토큰"은 원판과 같은 자로 줄어든 값이 된다.
- BVB처럼 작은 작업 공간에서는 Verus와의 차이 대부분(52%)이 고정 부분(언어 규칙 프롬프트, 도구 설명과 프롬프트 도구 절의 중복)이라 이 투영으로 줄지 않는다. 백로그 `2D-28`.
- 정식 하네스는 `BMB_CONTEXT_LOG=1`이면 요청별 토큰과 호출별 결과 바이트를 기록한다(기본은 꺼져 결과 행이 이전과 같은 바이트, 에이전트가 보는 것은 켜도 같다). T0-15는 켜고 돌려 분해를 추정 없이 낸다.
- 되돌리기: 플래그를 지운다. 기본값과 동결 집합은 이 결정에 기대지 않는다.

## 권장안: 기본값 전환(JUDGMENT §10, 사람 승인 안건)

1. **문제:** 에이전트가 보는 맵·증명 결과가 같은 정보를 담은 코드의 3배 크기이고, qwen 64K 문맥에서 세션 하나가 문맥 끝에 닿아 실패했다(m1b `w11-clamp-all`).
2. **원인과 층:** 도구 결과 형식(맵 필드를 그대로 보임, 성공한 상태 줄의 나열). 도구 층.
3. **정석 해:** 소스 꼴 시그니처 투영과 실패만 자세히 보이는 결과(rustdoc, 컴파일러의 진단 관례).
4. **후보:** (A) 지금 기본값 전환: C3 위반(진행 중 측정의 조건이 바뀜). (B) 선택 플래그로 두고 새 판을 측정한 뒤 전환: C1~C4 통과, S4 최선. (C) 맵 스키마에서 해시 제거: 다른 층(S2 위반). (D) JSON 유지와 필드 생략: 코드 대비 0.82~1.02로 확인 기준을 여유 있게 넘지 못함.
5. **권장:** (B). 갈린 기준은 C3과 S4.
6. **영향(정보):** 전환 뒤 동결 집합의 측정은 새 판으로. `compiler/README.md`, 프롬프트는 형식을 말하지 않아 그대로.
7. **필요한 승인:** 기본값 전환(측정 조건 변경, 채택된 측정 절차와 판 구성에 닿음).
8. **우회:** 없음.
