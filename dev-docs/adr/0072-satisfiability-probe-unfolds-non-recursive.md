# ADR-0072: 충족 가능성 검사의 탐침은 재귀 밖의 정의를 모두 매크로로 쓴다

- 상태: 채택 (자율 채택, AUTONOMY.md §4). ADR-0069의 탐침(공허 검사·사전조건 충족 검사)의 꼴을 넓힌다. 뜻은 그대로이고 해법기에 쓰는 꼴만 바뀐다. 증명 의무의 탐침(ADR-0067)과 전체 질의(ADR-0064)는 그대로다
- 날짜: 2026-10-31
- 관련: ADR-0064(매크로 꼴과 패턴 규칙), ADR-0067(의무의 탐침), ADR-0069(검사의 탐침), 백로그 T2-10

## 맥락

- ADR-0069 뒤에도 `proofs_are_not_vacuous`의 프로그램(112개)과 `bench/game`에서 공허 검사의 도달 지점 576개가 미결정(rlimit 393,554,937), 사전조건 충족 검사의 함수 62개가 미결정(143,739,379)이었다. 증명 의무 전체(V4·V8·V10)보다 크다.
- 미결정 질의(서로 다른 텍스트 113개·17개)마다 단언 한 종류씩 빼고 다시 풀어 원인을 나눴다(`dev-docs/experiments/T2-10`). 비재귀 `spec fn`의 양화 정의를 빼면 결정되는 것이 공허 검사 339개(rlimit 168,506,093), 사전조건 충족 58개(122,734,703)로 가장 크다. 대부분 `sat`(도달, 충족)이 답인데 Z3가 양화 정의 위의 모델을 만들지 못한다(ADR-0064·0067과 같은 현상). 이 정의들은 잎이 아니어서(다른 `spec fn`을 부른다) ADR-0067의 탐침에서도 양화였다.

## 결정

1. 공허 검사와 사전조건 충족 검사의 탐침(ADR-0069)에서는 재귀하지 않는 `spec fn`의 정의를 잎이 아니어도 매크로로 쓴다(`verify::Forms::SatProbe`, `Prog::axiom`의 `SAT_QUANTIFIED` 표지).
2. 단, 매크로는 그 질의에서 자신이 부르는 정의가 모두 매크로일 때만이다. 재귀 정의(양화 공리)나 패턴이 이름을 담아 양화로 남은 정의를 부르면 그 정의도, 그 위의 정의도 양화로 남는다(`axioms_in_forms`의 고정점). 매크로 꼴, 패턴 규칙, 범위 밖 값(`f!ext`)은 ADR-0064와 같다.
3. 답의 사용, 몫(`PROBE_SHARE`), 그 뒤의 전체 질의와 재시도는 ADR-0069 그대로다.

## 근거

- **원인과 귀속 층:** 해법기가 양화 정의 위에서 모델을 만들지 못하는 것이다. 층은 인코더다. 뜻은 같으므로(ADR-0064 결정 3: 매크로와 양화 공리의 모델은 서로 대응한다) `sat`·`unsat`은 전체 질의와 같은 답이다. 판정이 바뀔 수 있는 것은 미결정 → 결정뿐이다.
- **정석:** 비재귀 정의의 `define-fun`은 SMT-LIB의 정석 꼴이다(ADR-0064). 같은 목표를 여러 꼴로 짧은 몫부터 푸는 것은 ADR-0067의 근거와 같다.
- **재귀에 닿는 매크로를 빼는 이유(측정):** 비재귀 정의를 모두 매크로로 쓰면 `lib/sha256.bmb`의 지점 20개(`sha256::chained`: 상호 재귀 `chain.*`를 부른다)가 rlimit 50,000 안에서 끝나지 않고 120초 넘게 돌았다(rlimit이 세지 않는 검색, ADR-0064가 본 공허 검사 시간 초과와 같은 꼴). 재귀에 닿는 정의를 빼면 같은 질의들의 결정 수는 같고(공허 285, 사전조건 58) 질의당 0.13초 안이다.
- **증명 의무의 탐침은 바꾸지 않는다:** 의무의 탐침은 증명도 찾는다. 매크로를 넓히면 비선형 증명이 퇴행했다(ADR-0067의 "모든 잎 매크로"·"매크로 먼저"). 반례 질의(실패 코퍼스)에 같은 꼴을 쓸지는 따로 잰다(백로그 T2-11).
- **측정(같은 112 프로그램, T2-09 뒤 → 이 결정):** 공허 검사 rlimit 380,378,351 → 239,829,012, 미결정 지점 566 → 281, 반박 0 → 0. 사전조건 충족 143,739,379 → 20,619,118, 미결정 62 → 4(58개가 충족), 충족 불가 0 → 0. 실패 코퍼스: 공허 검사 5,503,225 → 4,394,478, 반박 지점과 보고 집합 그대로. 시간 177초 → 125초, 92초 → 14초. 남은 미결정의 원인(재귀가 낀 정의 164, 비트 연산 산술 56 등)은 백로그 T2-13. 자세히는 `dev-docs/experiments/T2-10/results.md`.

## 결과

- 두 검사의 판정은 같거나 더 결정된다. 보고(W0901·W0905)는 반박(`unsat`)뿐이고, 같은 뜻의 질의라 새 보고나 사라진 보고는 뜻이 아니라 결정 여부에서만 생긴다.
- 증명 의무의 질의 텍스트, 증명 캐시, V4·V7·V8·V10은 바뀌지 않는다(의무는 `Forms::Probe`·`Forms::Full`).
- 시험: `verify::tests::satisfiability_probe_unfolds_definitions_outside_recursion`, `satisfiability_probe_keeps_recursion_quantified`, `proofs_are_not_vacuous`, `compiler/tests/lint.rs`.
- 되돌리기: `Prog::axiom`이 잎이 아닌 정의에 `SAT_QUANTIFIED`를 붙이지 않으면 ADR-0069 그대로다.
