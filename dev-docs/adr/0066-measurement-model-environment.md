# ADR-0066: 측정 모델 환경: 기본은 `qwen3.8-27b`, 프런티어 교차 비교는 `claude-sonnet-5-5`

- 상태: 채택 (사람 승인 2026-10-30: "이 환경에서 두 모델 사용 승인, 가급적 qwen 모델을 사용하고, 프런티어 모델과 교차 비교할 때 sonnet을 사용한다". 벤치마크 환경 제공 지침)
- 날짜: 2026-10-30
- 관련: ADR-0021(측정 절차), ADR-0034(미션 목표), ADR-0058 §2(측정 경로: 파일럿 먼저, 정식 경로는 승인 대기), AUTONOMY.md §4(유료 API는 승인), 백로그 T0-03

## 맥락

- 모델이 있어야 재는 지표(G2·G3·G5·G8, H-SPEC·H-ORACLE·H-FAMILIAR 등)는 정식 측정 경로가 없어 파일럿(Claude Code CLI, ADR-0058 §2)으로만 쟀다. 파일럿 결과는 주장에 쓰지 않는다. 정식 경로(T0-03: 하네스가 에이전트 루프를 쥐는 API 실행)는 유료 API와 시크릿 설정이 사람 몫이라 10-24부터 막혀 있었다.
- 이 실행 환경은 모델 게이트웨이 `https://token.iyulab.com`를 제공한다. 자격 증명은 환경이 넣어 주므로 저장소와 명령에 키가 없다. 2026-10-30에 확인한 것:
  - `GET /openai/v1/models`: 모델 여섯. 생성 모델은 `qwen3.8-27b`(게이트웨이의 로컬 장비), `claude-sonnet-5-5`·`gpt-5.4-mini`·`gemini-3.8-flash`(외부 제공자).
  - `GET /anthropic/v1/models`: `claude-sonnet-5-5` 하나.
  - 텍스트 생성과 도구 호출: `qwen3.8-27b`는 `/openai/v1/chat/completions`(OpenAI 꼴 `tool_calls`), `claude-sonnet-5-5`는 `/anthropic/v1/messages`(Messages API 꼴 `tool_use`, `output_config.effort` 수용). 둘 다 성공했다.
  - 하네스 끝까지: m1의 `w01-clamp`(작성)·`n01-callers`(탐색)를 두 모델이 모두 성공했다(검증용 실행, 결과는 커밋하지 않음).

## 결정

1. **측정 모델은 이 환경의 게이트웨이를 쓴다.** 하네스의 에이전트 종류는 둘이다: `openai:MODEL`(Chat Completions), `anthropic:MODEL`(Messages API). 주소의 기본값은 게이트웨이이고 환경 변수(`BMB_OPENAI_BASE_URL`·`BMB_ANTHROPIC_BASE_URL`)로 바꿀 수 있다. 키는 저장소에 두지 않는다(`bench/m1/model_api.py`).
2. **기본 모델은 `openai:qwen3.8-27b`다.** 모델이 필요한 측정은 먼저 이 모델로 한다: 동결 과제 집합의 정식 측정, 새 과제 집합의 첫 실행, 언어·도구 변경 뒤의 재측정, 실패 원인 분석.
3. **`anthropic:claude-sonnet-5-5`는 프런티어 교차 비교에만 쓴다.** 같은 동결 집합을 같은 하네스·같은 커밋에서 qwen 실행 뒤에 한 번 돌려, 두 모델의 결과를 나란히 보고한다. 개발 중 반복이나 디버깅에는 쓰지 않는다.
4. **이 경로는 ADR-0021의 정식 측정이다(T0-03 해제).** 하네스가 에이전트 루프·도구 한도·판정을 쥐고, 행마다 모델과 설정(`agent_settings`)·토큰(`model_usage`)을 남긴다. 결과는 모델 이름을 붙여 주장 근거로 쓸 수 있다. 다른 모델에 일반화하지 않는다. CLI 파일럿(ADR-0058 §2)은 파일럿으로 남는다.
5. **실행 규칙(ADR-0021 그대로):** 과제마다 한 세션·재시도 없음, 동결 집합·프롬프트 그대로. (집합, 모델, 커밋)마다 한 번 돌리고, 돌린 결과는 모두 커밋한다. 나중 커밋에서 다시 재면 새 측정이며, 고르지 않고 이전 결과와 함께 보고한다. 전송 오류(연결, HTTP 429·5xx)만 같은 요청으로 다시 보내고 그 횟수를 `http_retries`로 남긴다. 이것은 과제 재시도가 아니다.
6. **사용 승인의 범위:** 이 두 모델을 위 목적으로 쓰는 실행은 실행마다 승인을 받지 않는다(AUTONOMY.md §4의 유료 API 행의 예외). 다른 모델(`gpt-5.4-mini`, `gemini-3.8-flash` 등), 다른 엔드포인트, 다른 목적은 여전히 승인이 필요하다.

## 근거

- **원인과 층:** 지표가 비어 있는 원인은 측정 경로가 없는 것(프로세스)이었다. 사람이 경로와 모델을 정했으므로 프로세스의 막힘이 풀린다(ADR-0058 §2의 해제 조건).
- **기본을 qwen으로:** 사람의 지침이다. 측정 근거로도 낫다. 로컬 장비의 공개 가중치 모델이라 같은 모델로 다시 잴 수 있고, 프런티어 모델보다 약한 모델에서 도구와 계약이 성공률에 기여하는지가 더 잘 드러난다(파일럿에서 큰 모델은 BRB 24/24로 변별되지 않았다).
- **교차 비교를 sonnet으로:** 결과가 한 모델의 특성인지 언어·도구의 특성인지 가르려면 성격이 다른 모델이 하나 더 있어야 한다. 지금까지의 파일럿(Claude Code CLI)과 같은 계열이라 파일럿 결과와도 이어서 볼 수 있다.

## 결과

- 하네스(`bench/m1`·`bench/brb`·`bench/bvb/verus`·`bench/bnb`)는 `model_api.make_model_agent`로 에이전트를 만든다. Anthropic 에이전트는 SDK 대신 표준 라이브러리 클라이언트를 쓴다(같은 `messages.create` 꼴, 설정은 그대로 `effort: high`).
- BRB의 MANIFEST는 `harness.py`를 담으므로 다시 동결했다. 바뀐 것은 에이전트 종류 분기와 `+dirty` 판정뿐이고 과제·프롬프트·판정은 그대로이며, BRB에는 아직 정식 측정 결과가 없다(파일럿만). 정식 결과가 생기기 전의 재동결은 선례가 있다(699ebdc0). m1·m1b·BVB의 MANIFEST는 하네스 코드를 담지 않아 그대로다.
- 하네스의 `+dirty` 판정은 `bench/*/results/`를 세지 않는다. 한 실행이 집합을 차례로 돌 때 앞 집합의 결과 파일 때문에 뒤 집합이 `+dirty`(보고 제외)로 찍히던 결함이다.
- 게이트웨이의 특성(2026-10-30, 첫 qwen 실행이 m1에서 멈춘 뒤 잼):
  - 스트리밍하지 않는 요청은 약 30초에 HTTP 502(`upstream request failed`)로 끊긴다. 같은 요청을 다시 보내도 같다. 그래서 어댑터는 모든 요청을 스트리밍(SSE)으로 보내고 사건을 비스트리밍 응답 꼴로 접는다. 같은 생성 16,000토큰이 스트리밍으로는 147초에 끝났다.
  - `qwen3.8-27b`의 문맥은 64K다. 프롬프트가 약 65,000토큰을 넘으면 HTTP 400이다. 재시도로 고쳐지지 않는 오류는 그 세션만 `stop: "api_error"`로 끝내고(메시지는 `model_usage.api_error`) 그때 상태로 판정한다. 보고서는 이 세션을 따로 센다.
  - 스트림이 중간에 끊기는 경우가 있다(프록시 터널 종료). 전송 실패로 보고 같은 요청을 다시 보낸다(최대 6번, 약 2분).
- qwen의 출력 한도는 32,768토큰이다(Qwen의 사고 모드 권장 길이). 16,000에서는 첫 차례가 추론만으로 한도를 쓰고 끝난 경우가 있었다(m1 `w05-fill-from`). sonnet은 기존 설정(16,000, `effort: high`) 그대로다. 비교군(BMB 대 Rust·Verus)은 같은 모델·같은 설정이므로 공정성(ADR-0034 §2)은 그대로다.
- `bench/run_models.py`는 `openai:`·`anthropic:` 둘을 받고 `ANTHROPIC_API_KEY`를 요구하지 않는다. 게이트웨이는 가격을 알려 주지 않으므로 가격 인자는 그대로 둔다(로컬 qwen은 0, sonnet은 제공자 가격표).
- 데이터: qwen은 게이트웨이의 로컬 장비에서 돈다. sonnet은 외부 제공자로 나가며 게이트웨이 표시로 보존 30일·학습 사용 없음이다. 보내는 것은 동결 과제와 BMB 코드뿐이다.
- 백로그: T0-03은 이 경로로 진행한다. qwen 정식 측정(m1·m1b·BVB·BRB)과 sonnet 교차 비교가 다음 태스크다.
- 2H(M2-e)의 미션 목표 판정은 이 측정으로 한다. 어느 모델의 값을 목표값과 비교할지는 2H에서 정한다. 그때까지는 두 모델을 함께 보고한다.
- 되돌리기: 이 ADR을 대체하는 ADR(사람 승인).
