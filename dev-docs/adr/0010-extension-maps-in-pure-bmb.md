# ADR-0010: 확장 맵 생성기는 BMB 순수 함수

- 상태: 채택
- 날짜: 2026-10-24
- 관련: DESIGN.md §6, ADR-0008, genesis Q9

## 맥락
확장 맵(ADR-0008)은 서드파티를 포함해 누구나 만들 수 있다. 이들의 결정론을 어떻게 보장할 것인가.

## 결정
확장 맵 생성기는 **BMB 순수 함수**로 작성한다.

## 근거
결정론이 규약이 아니라 언어가 증명하는 성질이 된다(효과 시스템이 `pure`를 검사).

## 결과
- 확장 맵 생성기를 쓰려면 언어가 맵 데이터를 다룰 만큼 성숙해야 한다. 첫 마일스톤에서는 표준 맵만 컴파일러가 직접 만든다.
- 효과 시스템의 `pure` 판정은 이 ADR의 전제다.
