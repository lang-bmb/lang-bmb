# ADR-0004: 설계서는 작성하지 않고 도출한다

- 상태: 채택
- 날짜: 2026-10-24
- 관련: DESIGN.md 원칙 1·2, ADR-0005, genesis Q4

## 맥락
착수 서술에 "인간과 AI는 설계서로 소통한다"가 있었다. 설계서를 사람이나 AI가 따로 작성하면 코드와 동기화를 누가 책임지는지가 문제다.

## 결정
설계서는 작성하지 않는다. 코드(유일한 정본)에서 결정론적으로 **도출**한다.

## 근거
작성된 설계서는 반드시 코드와 어긋난다. 도출하면 어긋날 수 없다.

## 결과
설계서에 들어갈 정보(의도, 근거, 계약)는 코드 안에 구조화되어 있어야 한다(ADR-0006, 원칙 3).
