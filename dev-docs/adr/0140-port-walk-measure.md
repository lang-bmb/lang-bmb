# ADR-0140: 포트의 구문 트리 순회는 남은 깊이를 측도로 한다

- 상태: 채택 (자율 채택, AUTONOMY.md §4: 포트의 구현 관례이고 받아들이는 언어를 바꾸지 않는다)
- 날짜: 2026-11-15
- 관련: ADR-0047 §3(구조적 측도), ADR-0100(동결), ADR-0121(포트의 자료 모양), ADR-0122(원장의 지표), `dev-docs/measurements/selfhost-port-map.md` §7.8, 백로그 4D-25

## 맥락

- 재귀 함수에는 `decreases`가 있어야 한다. 구조적 측도(`decreases e`)는 재귀 열거형과 자기를 `Vec`에 담는 구조체에만 쓸 수 있다(E0401).
- 포트의 구문 트리는 stage0의 모양을 따른다(ADR-0121): `Expr { kind: ExprKind, span }`의 `ExprKind`가 `Box<Expr>`·`Block`·`Vec<Expr>`를 담고, `Block`이 `Vec<Stmt>`를 담는다. 구조체와 열거형이 번갈아 서로를 담아 어느 타입에도 구조적 측도를 쓸 수 없다.
- 파서는 걸리지 않았다: stage0의 중첩 한도(256)가 그대로 측도가 됐다. 걸리는 것은 다 만든 트리를 걷는 함수다(`fmt` 전체, `plain_place`). 검사기(`4D-03`)의 순회가 모두 이 꼴이다.
- 트리의 깊이는 중첩 한도로 묶이지 않는다. 연산자 사슬이 왼쪽으로 쌓여 깊이 약 10만의 식이 한도 안에서 나온다(확인: 100단계 × 연산자 8종 × 120개, `dump parse`가 stage0과 포트에서 같다).

## 결정

1. **구문 트리를 걷는 재귀 함수는 남은 깊이 `f: usize`를 마지막 인자로 받고 `decreases f`로 쓴다.** 재귀 호출은 `f - 1`을 넘기고, 함수의 첫 문장이 `f == 0`이면 그만둔다.
2. **처음 주는 값은 닿을 수 없는 상한이다.** 둘 가운데 하나다: 입력이 주는 참 상한(파서 안에서는 토큰 수: 트리의 한 단계는 토큰을 하나 이상 쓴다), 또는 실행 스택이 버티지 못하는 깊이(`1000000000`). 뒤의 것은 `f == 0`에 닿기 전에 스택이 넘친다는 뜻이고, stage0도 그 깊이에서 같은 식으로 끝난다.
3. **`f == 0`의 갈래는 닿지 않는 갈래로 센다.** 원장의 마찰에 적고(ADR-0122 결정 7), 그 갈래가 내는 값(빈 글, `false`)에 뜻을 두지 않는다.
4. **구조적 측도를 넓히는 것은 지금 하지 않는다.** 받아들이는 프로그램이 느는 변경이고(ADR-0100의 예외 절차), 증명기의 변경은 포트가 다시 옮겨야 할 양이다. 부트스트랩 뒤의 언어 작업으로 남긴다(백로그 4D-25의 후속).

## 근거

| 안 | 판정 |
| --- | --- |
| **남은 깊이 인자(채택)** | 언어를 바꾸지 않는다. 최소 실험(`dev-docs/experiments/port-shape/tree.bmb`)과 파서·`fmt` 포트(함수 33개)가 이 꼴로 전부 증명됐다. 비용은 인자 하나와 닿지 않는 갈래 하나씩이다 |
| 구조적 측도를 상호 재귀 타입으로 넓힌다 | 원인의 층(언어)에서 고치는 길이지만 동결 중의 표면 변경이다. 증명 인코딩(재귀 타입의 크기 함수)과 검사기를 바꾸고, 그 변경을 포트가 다시 옮긴다. 급하지 않다: 우회가 증명을 막지 않는다 |
| 구문 트리를 열거형만으로 다시 짠다 | 구조적 측도가 선다. 그러나 stage0과 자료 모양이 달라져 구성 요소별 차등 시험의 대응(ADR-0121)이 깨지고, `Vec<Stmt>`를 담는 `Block`은 여전히 걸린다 |

## 결과

- 검사기 포팅(`4D-03`)의 순회는 이 관례로 쓴다. 백로그 4D-25는 이 결정으로 닫는다.
- 되돌리는 방법: 구조적 측도가 넓어지면 `f` 인자와 `f == 0` 갈래를 지우고 `decreases`를 트리로 바꾼다. 함수의 뜻은 그대로다(닿지 않는 갈래만 사라진다).
- 종료의 증명 가운데 실행 때의 상한에 기댄 것의 목록은 포팅 원장이 구성 요소별로 든다(포팅 지도 §7.8의 "읽는 법" 2).
