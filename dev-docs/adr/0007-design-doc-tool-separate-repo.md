# ADR-0007: 설계서 도구는 별도 리포, 마크다운 1순위

- 상태: 채택
- 날짜: 2026-10-24
- 관련: DESIGN.md §1·§6, ADR-0005, genesis Q6

## 맥락
언어 밖의 설계서 도구(ADR-0005)를 어디에 두고 어떤 형태로 출력할 것인가.

## 결정
별도 리포로 둔다. 출력은 **마크다운이 1순위**다.

## 근거
마크다운은 도구 없이도 읽히고, git에서 diff가 된다. 별도 리포로 두면 언어 리포는 맵이라는 계약만 지키면 된다.

## 결과
설계서 도구는 첫 마일스톤 범위 밖이다(ADR-0016).
