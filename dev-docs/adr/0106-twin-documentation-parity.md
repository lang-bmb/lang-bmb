# ADR-0106: 포팅 쌍둥이의 문서 조건: Rust 팔은 주석 없이, 주석 있는 대조 조건을 함께 등록

- 상태: 채택(자율 채택, AUTONOMY §4 "결정 기록": ADR-0104 결정 4 "공정성을 먼저 정한다"의 측정 조건. 여덟째 실행 계획 "3P 공정성")
- 날짜: 2026-11-10
- 관련: ADR-0104(포팅 쌍둥이), ADR-0103(증거 단계, 주장의 기준 모델), ADR-0019(정규형), ADR-0006(근거를 노드 해시에), DESIGN.md §2 표 "주석", `bench/twin/README.md` "공정성", 백로그 3P-02~05

## 맥락

- `bmb import`가 만드는 작업 공간은 정규형이라 `//`·`///` 주석을 버린다. 남는 것은 단위의 `#[summary]`, 계약, 이름이다. Rust 팔은 크레이트를 그대로 받아 문서 주석과 줄 주석을 모두 본다.
- 고정 장치 `stk`는 두 쪽에 같은 문서를 적었지만 BMB 팔에는 보이지 않는다. stage0(약 5만 줄)은 주석이 많다. 백로그 ID, 설계 근거, 불변식 설명이 주석에 있다.
- 그대로 재면 차이가 언어·도구의 차이인지 정보량의 차이인지 가를 수 없다. 이해 과제(H-COMPREHEND)에서 특히 그렇다.
- BMB에는 정의 단위의 자유 문서 통로가 없다. DESIGN.md §2는 주석 대신 "노드 해시에 묶인 구조화 근거"를 두지만, 지금 그것(`#[rationale]`)은 탈출구에만 붙는다(ADR-0029). BMB 쪽에 문서를 싣는 것(정규형이 `///`를 지키거나, 맵에 정의 문서를 싣는 것)은 정규형·표면의 결정이다(ADR-0019). 자율 범위 밖이고, 동결(ADR-0100) 전에 정해야 한다.

## 결정

1. **측정 조건(주 조건): Rust 팔은 주석 없는 크레이트를 받는다.** `pair.py`의 `materialize`가 `.rs` 파일마다 `strip_comments`를 적용한다.
   - 지우는 것: `//`·`///` 줄과 꼬리, `/* */`(중첩)·`/** */`.
   - 남기는 것: 모듈 안쪽 문서 `//!`. BMB 단위의 `#[summary]`에 대응한다.
   - 문자열, 바이트 문자열, raw 문자열, 문자, 수명은 그대로 둔다.
   - 그러면 두 팔이 보는 정보는 이름, 타입, 코드, 단위 요약이다. 여기에 BMB의 계약이 더해진다. 계약은 BMB가 주장하는 차이 자체다.
2. **대조 조건: 주석 있는 Rust(`PAIR_RUST_COMMENTS=keep`).** 같은 과제·커밋에서 sonnet 1회(ADR-0103 결정 3의 기준 모델)를 돈다. Rust 팔만 다시 돈다.
   - 주 조건에서 BMB가 앞서도, 대조 조건에서 그 차이가 최소 차이 D(ADR-0077) 안으로 줄면, 주장은 "주석 없는 Rust 대비"로 한정해 적는다.
   - 대조 조건에서도 D를 넘게 앞서면 한정 없이 적는다.
   - 이 규칙은 3P-05 첫 실행 전에 이 커밋으로 등록한다.
3. **범위 판정은 주석 없는 원문으로.** BMB 정규형은 에이전트가 쓴 주석을 버린다. 그래서 Rust 팔의 정의 원문도 주석을 지운 뒤 비교한다(`rust_defs`). 주석만 고친 정의는 바뀐 정의가 아니다. 두 조건 모두 같다.
4. **제거기의 게이트.** `pair.py check`가 고정 장치마다 주석 있는 크레이트와 지운 크레이트를 둘 다 빌드한다. 두 쪽이 말뭉치의 출력 바이트와 같아야 한다(같은 프로그램). 오라클과 약한 대조군도 주 조건에서 돈다. `test_pair.py`의 `Comments`가 문자열·raw 문자열·중첩 블록·문자·수명을 덮는다.
5. **BMB 쪽 문서 통로는 사람의 결정으로 남긴다.** 승인되면 그 판을 세 번째 조건으로 더하고, 주 조건은 그때 다시 정한다. 이 ADR은 그 결정을 기다리지 않는다.

## 근거

| 안 | 판정 |
| --- | --- |
| **Rust 주석 제거 + 주석 있는 대조 조건(채택)** | 두 팔의 정보가 같아 차이를 언어·도구에 귀속할 수 있다. Rust를 약하게 만드는 쪽의 편향은 대조 조건이 크기를 잰다 |
| 각 언어를 쓰는 그대로(Rust 주석 유지만) | 현실적이지만 정보량 차이가 결과에 섞인다. 귀속할 수 없다 |
| BMB 쪽에 문서를 싣기 | 정규형·표면 결정(ADR-0019)이라 자율 범위 밖. 결정 5로 사람에게 넘긴다 |
| 고정 장치의 문서를 두 쪽에서 지우기만 | stage0 포트에서 매번 손으로 해야 하고, 빠뜨림을 잡는 게이트가 없다 |

## 결과

- `bench/twin/README.md` "공정성" 절이 이 결정을 가리킨다.
- 3P-05의 실행 계획에 대조 조건(sonnet 1회, Rust 팔)을 넣는다.
