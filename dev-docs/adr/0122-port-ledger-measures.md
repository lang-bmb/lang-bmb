# ADR-0122: 포팅 원장의 지표 정의

- 상태: 채택(사람 승인 2026-11-11 "모두 채택"). ADR-0116 결정 2·3의 수치를 정의한다
- 날짜: 2026-11-11
- 관련: ADR-0116(관문 B0), ADR-0111(관문 B·C), ADR-0113(고정), HEALTH.md S7, `dev-docs/measurements/port-ledger.md`, `scripts/components.py`, 백로그 4D-08·4D-12

## 맥락

- ADR-0116은 관문 B0에서 "계약 없는 배율과 증명한 배율", "증명된 정의 비율", "미결정 의무가 작성 비용의 과반"을 보라고 정했지만 재는 법을 정하지 않았다.
- "계약 없는 배율"을 판 둘(계약 없는 판, 증명한 판)을 따로 써서 재면 판을 쓰는 순서와 사람에 따라 값이 달라지고 비용이 두 배다.
- "미결정 의무"와 "작성 비용"은 단위가 다르다(의무의 수, 토큰).
- `bmb verify`의 상태 `verified`에는 탈출구에 기댄 정의(`trust`가 `assumed`·`external`)가 들어 있다.

## 결정

1. **줄 수는 정규형(`bmb fmt`)의 줄이고, 명세 줄은 기계가 가른다.** 명세 줄은 증명만 읽는 줄이다: `spec fn`·`proof fn` 항목, `proof { }` 블록, 그리고 절(`requires`·`ensures`·`invariant`·`decreases`), `assert(`, 속성 `#[uses]`·`#[invariant]`·`#[trigger]`로 시작하는 줄(`scripts/components.py`의 `spec_lines`). 나머지가 실행 줄이다.
2. **배율은 둘이다.** 실행 배율 = 실행 줄 / stage0 줄, 전체 배율 = 포트 줄 / stage0 줄. stage0 줄은 포팅 지도 §7.1의 규칙(첫 `#[cfg(test)]` 앞)이다. ADR-0116의 "계약 없는 배율"은 실행 배율로, "증명한 배율"은 전체 배율로 읽는다. 판을 둘 쓰지 않는다.
3. **증명된 정의는 신뢰 사실 없이 증명된 정의다.** `status`가 `verified`이고 `trust` 키가 없는 것만 센다. 분모는 상태 줄이 나온 모든 정의다. 이 비율이 S7이고 관문 B0의 "C2의 증명된 정의 비율"이다. 탈출구(`#[external_body]`, `assume`)는 따로 센다.
4. **증명 비용은 의무 수와 `rlimit` 합이다.** 둘 다 `bmb verify`의 상태 줄에서 온다. 관문 B0의 전체 추정은 구성 요소의 실측값(줄당 의무, 줄당 `rlimit`)에 남은 stage0 줄과 전체 배율을 곱한다.
5. **작성 비용은 세션 기록 셋이다.** 구성 요소의 포트는 위임된 세션에서 쓰고 그 세션의 기록을 `components.json`의 `ledger`에 옮긴다: 세션 토큰(하네스가 보고한 합), 게이트 실행(`bmb verify`를 돌린 횟수), 미결정으로 끝난 실행(그 가운데 남은 오류가 E0811뿐이던 횟수).
6. **ADR-0116 결정 3의 "미결정 의무가 작성 비용의 과반"은 "미결정으로 끝난 실행이 게이트 실행의 과반"으로 잰다.** 단위가 같은 두 수의 비다.
7. **마찰은 진단 코드와 처리를 적는다.** 한 줄에 무엇이 걸렸는지, 진단 코드, 처리(백로그 ID, 우회, 그대로)를 적는다. 판정기의 완전성 결함은 백로그에 올린다.

## 근거

| 안 | 판정 |
| --- | --- |
| **한 판을 기계로 가른다(제안)** | 재현된다(같은 파일이면 같은 값). 최소 실험(`dev-docs/experiments/port-shape/`)의 두 파일에서 기계 분류가 손으로 센 값과 같았다 |
| 계약 없는 판과 증명한 판을 따로 쓴다 | 비용이 두 배이고, 증명을 위해 바꾼 실행 코드(가드, 자료 구조)가 두 판의 차이에 섞인다 |
| 토큰 대비 미결정 의무 | 단위가 달라 "과반"이 정의되지 않는다 |

실행 배율은 "증명 없이 쓴 판"의 배율보다 클 수 있다: 증명을 위해 넣은 실행 코드(길이 가드 같은)가 실행 줄로 세어진다. 그 코드는 마찰 칸에 적는다.

## 결과

- 포팅 원장의 열이 바뀐다: 명세 줄, 실행 배, 전체 배, 의무, `rlimit`, 게이트 실행, 미결정으로 끝난 실행.
- `components.json`의 `ledger` 키가 `gate_runs`·`undecided_runs`로 바뀐다(포트가 아직 없어 옮길 값은 없다).
- 채택되면 `4D-12`의 완료 기준을 이 정의로 읽는다.
