# ADR-0100: stage0 기능 동결

- 상태: 제안 (백로그 4D-01, 선언은 사람 승인)
- 날짜: 2026-11-09
- 관련: ADR-0037 §3(포팅 기간의 stage0 기능 동결), `dev-docs/measurements/selfhost-port-map.md`(포팅 지도, §6 동결 전 정리), ADR-0095·0096(문법 결정), ADR-0097~0099(열린 표면 결정), ROADMAP ⑤·⑥

## 맥락

- ADR-0037은 포팅 착수 때 stage0(Rust 컴파일러)의 기능을 동결하고, 그 뒤 stage0 변경은 버그 수정과 부트스트랩에 필요한 최소 변경만이라고 정했다. 포팅은 구성 요소마다 stage0과 같은 바이트를 내는 차등 시험으로 진행한다(P0~P11). stage0의 언어가 움직이면 포팅한 쪽이 계속 따라가야 한다(v0의 이중 유지 비용).
- 동결이 측정 가능하려면 "언어가 바뀌었다"를 기계가 알아야 한다. 지금은 그 검사가 없다.
- 열린 표면 결정이 넷 남아 있다: ADR-0097(경계가 다른 `impl` 블록), ADR-0098(명세가 옮긴 값을 읽음), ADR-0099(명세 정수 넓힘), 2V-18(ADR-0052 상수·ADR-0053 클로저). 동결 뒤에는 이것들이 BMB 컴파일러 쪽에서만 들어갈 수 있다(ADR-0037 결과).

## 결정(제안)

1. **동결 대상은 받아들이는 언어다.** 구문, 타입·이동·효과 검사, 진단 코드 표, 정규형(`fmt`), 정체성 해시(`hash`), 증명 의무의 뜻이다. 증명기의 비용(rlimit)과 도구·벤치·문서는 대상이 아니다.
2. **감지는 표면 지문이다(`scripts/surface.py`, `dev-docs/health/surface.json`).** 코퍼스 프로그램마다(`tests/check`·`tests/verify`·`tests/run` 파일 하나씩, `lib/std` 하나) 원문 다이제스트와 `bmb check`(진단·종료 코드)·`fmt`·`hash` 출력의 다이제스트를 두고, 진단 코드 목록을 둔다. 원문이 그대로인데 결과가 바뀐 항목과 더하거나 뺀 코드가 "표면 변경"이다. 게이트 단계 `surface (4D-01)`가 돌린다.
3. **동결 전에도 지문은 따라간다.** `"frozen": false`인 동안 표면 변경에는 사유가 필요 없지만, 같은 커밋에서 `scripts/surface.py record`로 지문을 갱신하지 않으면 게이트가 실패한다(동결이 낡은 지문에서 시작하지 않도록). 선언(승인) 때 `true`로 바꾸면 사유 있는 예외가 필요하다.
4. **예외는 사유와 함께 적는다.** 버그 수정(건전성, 멈춤, 잘못된 진단)과 부트스트랩 필수 변경만이다. 항목마다 `{"kind", "name", "reason"}`(사유에 백로그 ID)를 `exceptions`에 적고 `scripts/surface.py record`가 `history`로 옮긴다. 같은 변경을 포팅한 쪽에도 같은 커밋 묶음에서 반영한다(포팅 지도 §5 위험).
5. **선언의 전제(이것이 다 닫혀야 승인을 구한다).** (a) ADR-0097·0098·0099·0052·0053을 채택하거나 폐기하고 채택한 것을 구현, (b) 2R-05(바뀐 표면의 A/B)와 2H-02(3단계 범위), (c) 포팅 지도 §6의 동결 전 정리(4A-03 완료).

## 근거(검토한 대안)

| 안 | 판정 |
| --- | --- |
| **코퍼스 결과 지문, 원문이 같은 항목만 비교(권장)** | 코퍼스를 고치거나 더하는 것은 변경이 아니고, 컴파일러가 같은 원문을 다르게 받는 것만 잡는다. 3초(219 프로그램, 코드 178). 감도 확인: ADR-0095 앞 컴파일러(`99138a9d`)에 돌리면 코드 5개 차이와 결과가 바뀐 프로그램 68개를 보고한다 |
| 태그만 찍고 감지 없음 | 동결이 선언일 뿐 측정 가능한 기준이 아니다(genesis §3.5) |
| 파서·검사기 소스 파일의 변경 감지 | 버그 수정·리팩터링과 언어 변경을 가르지 못한다. 결과가 같은 변경도 막는다 |
| 증명 판정까지 지문에 | 증명 비용·시드는 동결 대상이 아니고(결정 1), 판정은 이미 기존 게이트가 고정한다. 지문이 느려진다 |

## 결과

- `scripts/surface.py`, `scripts/test_surface.py`, `dev-docs/health/surface.json`(지금 `frozen: false`), 게이트의 `surface (4D-01)` 단계.
- 동결 전에 언어를 바꾸는 커밋은 `scripts/surface.py record`로 지문을 갱신한다(바뀐 항목은 `check`가 보고하고, 갱신하지 않으면 게이트가 실패한다).
- 동결 선언은 이 ADR의 채택과 `frozen: true` 커밋 하나다.
