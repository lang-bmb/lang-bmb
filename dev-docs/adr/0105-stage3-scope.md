# ADR-0105: 3단계 범위: 판정은 포팅 쌍둥이, 도구 페이즈는 측정된 필요로 연다

- 상태: 제안(백로그 2H-02). 승인은 2H-01(ADR-0103) 결과를 붙여 구한다. 결정 4의 조건 규칙은 그 결과를 보기 전에 등록한다
- 날짜: 2026-11-09
- 관련: ADR-0104(포팅 쌍둥이), ADR-0103(증거 단계), ADR-0102(G5-L), ADR-0037(부트스트랩), ADR-0059(보존형 리팩터링의 전제), ADR-0100(stage0 동결), ROADMAP 3단계, 백로그 3A·3P

## 맥락

- 3단계 페이즈(3A~3E)는 ADR-0104 전에 정했다. 3A(대형 코퍼스)는 합성 생성기 BNB로 채웠고 3A-01~05는 끝났다. 남은 것은 3A-06(크기 축, 모델 팔은 2H-01), 3A-07(H-REUSE 판정기), 3A-08(수정 과제)이다.
- ADR-0104로 주 측정 장이 포팅 쌍둥이가 됐다. 쌍둥이는 포팅이 P3(검사기)까지 차등 시험을 통과해야 생긴다. 포팅은 동결(4D-01) 뒤다. 그래서 3단계의 판정 시점은 4D 진행에 묶인다.
- 3B(확장 맵), 3C(보존형 리팩터링 연산), 3D(대가 회수)는 도구 기능이다. 지금 계획은 측정 전에 만들게 돼 있다. 운영 규칙은 "차별점 가설은 그 위에 쌓기 전에 최소 실험으로 측정한다"다.
- 도구(맵, 질의, 작업 공간)는 동결 대상이 아니다(ADR-0100 결정 1). 그러나 P5(맵), P9(도구), P10(작업 공간) 포팅 뒤에 바꾸면 두 쪽을 고쳐야 하므로, 도구 변경도 그 포팅 전이 싸다.

## 결정(제안)

1. **3단계 통과 기준(3E)은 포팅 쌍둥이에서 판정한다.** 3P-05(P0~P3 크기)와 3P-06(P0~P7, 전체)의 H-COMPREHEND·H-REFACTOR·H-TASK, H-SCALE 기울기, G5-L(ADR-0102)이 판정이다. BNB의 기준(1만 정의에서 파일 기반의 1/3 이하 토큰, 정확도 동등 이상)은 보조 판정으로 남는다. G7은 BCB(2A-14e)가 판정한다.
2. **3A는 셋만 남기고 닫는다.**
   - 3A-06은 2H-01의 BNB 모델 실행으로 끝난다.
   - 3A-07(H-REUSE 판정기)은 3P-03·3P-04의 범위 판정기에 그대로 쓴다.
   - 3A-08(수정 과제의 재증명 범위)은 3P-03·3P-04로 옮긴다. Verus 쌍둥이와의 비교는 BVB에 남는다.
   - 합성 코드베이스 확장은 하지 않는다.
3. **3B·3C·3D는 측정된 필요로만 연다.**
   - **3C(보존형 리팩터링 연산):** 3P-03을 먼저 정의 단위 `write`만으로 돈다. 다음 중 하나일 때 연산(이름 바꾸기, 이동, 분할, 병합)을 만들고 같은 과제로 다시 잰다: H-REFACTOR가 반증되거나, 실패의 과반이 범위 밖 변경과 호출 한도에 귀속되는 경우.
   - **3B(확장 맵, 다중 관점 뷰):** 3P-02의 실패 귀속에서 없는 뷰(효과 경로, 데이터 흐름, 증명 의존)가 원인인 실패가 과반일 때, 그 뷰만 연다.
   - **3D(대가 회수, 동형 병합):** 3P-04의 실제 코드 중복 측정(3A-07 판정기) 뒤에 판단한다.
4. **2H-01 결과에 따른 우선순위(측정 전 등록).**
   - BNB 모델 실행(3A-06)에서 sonnet이 1만 정의에서 정확도가 Rust 팔보다 D를 넘게 낮거나, 토큰 비율이 1/3을 넘으면, 질의 표면 수정(2D-17 계열)을 3P-02보다 먼저 한다. 그 수정은 P5 포팅 전에 끝낸다.
   - H-EDIT(T1-41)에서 쓰기 판이 원판보다 D를 넘게 뒤지면 ADR-0101을 다시 열고, 3P-01 BMB 팔의 쓰기 도구를 그 결과로 정한다.
   - 그 밖의 결과(H-ENCAP, H-GAME, H-ORACLE의 성립·반증)는 3단계 순서를 바꾸지 않는다. 가설 등록부와 효용 보고서에만 반영한다.
5. **3단계와 4단계의 순서.**
   - 3P-01~04(하네스, 과제 생성기, 판정기)는 동결 전에 고정 장치(작은 쌍둥이 표본)로 만들고 오라클 팔로 게이트에 건다.
   - 3P-05는 P3 포트가 차등 시험을 통과한 뒤 돈다.
   - 측정이 포팅 순서를 정하지 않는다(ADR-0104 결과).

## 근거

| 안 | 판정 |
| --- | --- |
| **포팅 쌍둥이 판정, 도구 페이즈는 측정된 필요로(제안)** | 3단계 주장이 실제 코드에서 판정된다. 도구는 실패 귀속이 요구할 때만 만든다(운영 규칙 "먼저 측정") |
| 기존 3A~3E 그대로 | 합성 코드가 판정 장이고, 3B·3C·3D를 근거 없이 먼저 만든다 |
| 3C를 3P 전에 구현 | ADR-0059의 전제는 충족됐지만, `write`만으로 H-REFACTOR가 성립하면 연산 표면은 비용만 늘린다 |
| 3단계 판정을 포팅 완료 뒤로 | 크기 축(P3·P7·전체)을 잃고, 도구 수정이 포팅 뒤에 나와 두 쪽을 고친다 |

## 결과

- 승인되면: ROADMAP 3단계 표(3A~3E)를 이 결정으로 다시 쓰고, 백로그의 3A-08을 3P로 옮기고, 3B·3C·3D 행에 여는 조건을 적는다.
- 결정 4의 규칙은 2H-01 결과가 나오기 전 커밋(이 ADR의 첫 커밋)으로 등록된 것이다.
- 4D-01(동결 선언)의 전제 2H-02는 이 ADR의 승인이다.
