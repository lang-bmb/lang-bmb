# ADR-0071: 고정 문맥: 도구 문서는 도구 설명 한 곳에, 프롬프트 언어 규칙은 진단으로 배울 수 없는 것만

- 상태: 채택 (자율 채택, AUTONOMY.md §4: MCP 서버의 선택 플래그와 새 측정 판. 기본 출력과 동결 집합은 그대로). 기본값 전환은 §4의 측정 뒤 사람 승인 안건
- 날짜: 2026-10-31
- 관련: DESIGN.md 원칙 6, ADR-0021(동결), ADR-0068(압축 투영, 같은 절차), ADR-0070(같은 조건), 백로그 2D-25·2D-28·T0-17

## 맥락

- 2D-25: BVB `write` 판의 마지막 요청에서 Verus와의 차이 52%가 매 요청에 들어가는 고정 부분이다(2,467 대 803추정 토큰). 시스템 프롬프트의 도구 절(395토큰)은 도구 설명을 다시 말하고, 언어 규칙 절(726토큰)은 마일스톤 1에 동결된 금지 목록이다.
- 탐침(`dev-docs/experiments/context-size/rules.md`): 규칙 절의 위반 40개 중 7개는 지금 받고(낡은 금지), 거부 33개 중 24개는 진단이 `fix`로 고칠 꼴을 준다.
- 프롬프트와 도구 설명은 진행 중·예정 측정의 동결 조건이다(ADR-0021, ADR-0070 (a)·(c)).

## 결정

1. **도구 문서는 도구 설명 한 곳.** `bmb mcp --tool-docs`는 프롬프트에만 있던 도구 문서(질의마다 돌려주는 것, `units`부터 좁혀 가기, `write`가 유일한 쓰기 길)를 `query`·`write` 설명에 담고, 설계 참조(ADR·백로그 번호)를 빼며, `write` 인자는 스키마에서만 설명한다. 이름·인자는 같다. `--compact`와 함께 쓰면 결과 형식 문장도 그대로 붙는다. 플래그가 없으면 `initialize`·`tools/list`가 이전과 같은 바이트다.
2. **프롬프트 언어 규칙은 둘만.** (가) 진단이 고칠 길을 주지 않는 규칙, (나) 에이전트가 쓰는 거의 모든 정의에 걸리고 Rust·Verus와 달라 진단으로 배우면 세션마다 거부된 쓰기를 거의 확실히 치르는 규칙. 그 밖의 규칙은 진단에 맡기고 그렇다고 한 줄로 말한다. 지금 남는 것: 전체 경로, 효과·반환 타입·`let` 타입, 이름 붙은 술어 계약, 불투명 술어와 `#[uses]`, `#[trigger]`.
3. **측정 판.** `bench/lean/gen.py`가 동결된 `m1b-write`·`bvb-write`에서 `m1b-write-lean`·`bvb-write-lean`을 만든다: 도구 절을 지우고 언어 규칙 절을 2의 다섯 줄과 한 줄로 바꾸며, 서버 플래그 `--tool-docs`를 더하고 어떤 과제도 쓰지 않는 `build`를 숨긴다. 시드·과제·변이체·예제·작업 방법은 같은 바이트다. 생성해 MANIFEST와 함께 동결했고(ADR-0021 §1), 게이트가 생성 결과와 같음과 기준·약한 해법의 통과·거부를 본다(`bench/lean/test_gen.py`).
4. **기본값 전환의 조건.** `T0-17`이 이 판을 원판(`*-write`, T0-13)과 같은 조건(ADR-0070)에서 qwen, 이어서 sonnet으로 돌려, 작성·탐색 1회 성공률과 BSB 판별률이 원판보다 낮지 않고 요청당 프롬프트 토큰이 줄면, `--tool-docs`를 기본으로 하고 모든 판의 프롬프트를 같은 기준으로 다시 쓰는 ADR을 사람 승인으로 올린다. 바꾼 뒤의 측정은 새 판 이름으로 보고한다.

## 근거

- **원인 층(JUDGMENT §3):** 도구 절의 중복은 문서가 두 곳에 있는 것이 원인이다. 도구를 설명하는 곳은 MCP 도구 설명(도구 층)이고, 프롬프트는 도구 목록을 다시 쓸 이유가 없다(S3: 한 가지 일에 한 곳). 언어 규칙 절은 언어 층의 비용이지만, 진단이 고칠 길을 주는 규칙을 미리 가르치는 것은 원칙 6(도구가 할 수 있는 일을 에이전트에게 맡기지 않는다)의 반대 방향이다.
- **정석(S1):** MCP는 도구 설명과 입력 스키마를 도구 문서의 자리로 정한다. 컴파일러가 진단으로 언어 규칙을 가르치는 것은 rustc의 `help:`·제안 관례다.
- **대안:** (가) 하네스가 `set.json`으로 도구 설명을 덮어씀: 도구 문서가 측정 자산으로 옮겨 가 다른 층(S2 위반). (나) 프롬프트에서 도구 절만 지우고 설명은 그대로: 질의 의미가 사라진다(정보 손실). (다) 규칙 절을 통째로 지움: 진단이 고칠 길을 주지 않는 `crate::` 경로와 모든 정의에 걸리는 규칙이 세션마다 거부를 낳는다. (라) 이 결정.
- **효과(추정, `fixed.md`):** 고정 부분 BVB 2,467 → 1,528(−38%), m1b 2,433 → 1,494(−39%). Verus와의 고정 차이 1,664 → 725. 규칙을 진단으로 배우는 비용과 성공률은 추정하지 않고 측정한다(§4).

## 결과

- 낡은 금지(지금 받는 구문)는 동결된 원판에 그대로 있다. 새 판만 지금 언어와 맞는다.
- 진단 쪽 빈칸: `crate::`·`super::` 경로는 고칠 길 없는 구문 오류다(백로그 `2D-29`).
- 되돌리기: 플래그와 판을 지운다. 기본값과 동결 집합은 이 결정에 기대지 않는다.
