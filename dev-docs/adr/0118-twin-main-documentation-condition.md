# ADR-0118: 쌍둥이 측정의 주 문서 조건은 정의 요약 대 `///`

- 상태: 채택(사람 승인 2026-11-11 "모두 권장안 채택", 안건 D2. 백로그 3P-09, ADR-0106 결정 5가 미룬 주 조건의 재결정)
- 날짜: 2026-11-11
- 관련: ADR-0104(포팅 쌍둥이), ADR-0106(문서 조건: 결정 1·2를 이 ADR이 바꾼다), ADR-0117(정의 요약), ADR-0077·0112(최소 차이 D, 차이의 구간), ADR-0103 결정 3(기준 모델)

## 맥락

- ADR-0106은 BMB에 정의 문서의 통로가 없어서 Rust 팔의 주석을 지우는 조건을 주 조건으로 삼았고, 통로가 생기면 주 조건을 다시 정한다고 적었다(결정 5).
- ADR-0117로 정의 요약이 생겼다. 원문의 `///`는 정규형의 `#[summary("..")]`가 되고 맵 L1에 실린다.
- 실제 Rust 코드에는 `///`가 있다. 주석을 모두 지운 Rust는 Rust를 쓰는 방식이 아니어서, 그 조건에서의 우위는 "주석 없는 Rust 대비"로만 적을 수 있었다(ADR-0106 결정 2).

## 결정

1. **주 조건(`PAIR_DOCS=summary`, 기본값):** BMB 팔은 정의 요약을 갖고 Rust 팔은 같은 글의 `///`를 갖는다. Rust 쪽의 나머지 주석(`//`, `/* */`, `/** */`)은 지운다. 단위 요약과 `//!`는 ADR-0106대로 둔다.
2. **같은 글의 뜻:** 고정 장치에서 BMB 정의의 `///`(줄은 공백으로 잇는다)는 같은 이름의 Rust 항목의 `///`와 글자 그대로 같다. Rust 쪽은 그 뒤에 `Requires ..`·`Ensures ..`로 시작하는 문장만 더할 수 있다. BMB 팔이 계약으로 읽는 것을 Rust 팔이 글로 읽게 하기 위해서다. 그 밖의 문장은 두 쪽에 다 있거나 다 없다.
3. **BMB에만 있는 정의:** `spec fn`·`proof fn`에는 고정 장치에서 요약을 달지 않는다. Rust 팔에 대응 항목이 없어서 한쪽만 문서를 더 갖게 된다.
4. **보조 조건(`PAIR_DOCS=none`):** 두 팔 모두 정의 문서가 없다(ADR-0106의 옛 주 조건에서 BMB 쪽 요약도 뺀 것). 주 조건의 차이가 문서에서 오는지를 본다.
5. **대조 조건(`PAIR_DOCS=all`):** Rust 크레이트를 쓰인 그대로 준다. BMB 팔은 주 조건과 같다.
6. **주장의 한정 규칙(ADR-0106 결정 2를 바꾼다):** 효용 주장은 주 조건의 결과로 적는다. 대조 조건에서 차이가 D 안으로 줄면 "문서 주석만 있는 Rust 대비"로 한정한다. 보조 조건은 판정에 쓰지 않고 차이의 귀속에만 쓴다. 보조·대조 조건은 같은 과제·커밋에서 sonnet 1회이고, 대조 조건은 Rust 팔만, 보조 조건은 두 팔을 다시 돈다.
7. **범위 판정은 그대로다**(ADR-0106 결정 3): Rust 정의 원문은 주석을 모두 지운 뒤 비교하고, BMB의 해시는 요약을 읽지 않는다(ADR-0117). 문서만 고친 정의는 바뀐 정의가 아니다.
8. **게이트:** `pair.py check`가 고정 장치마다 세 조건의 Rust 크레이트와 두 조건의 BMB 원문을 빌드해 말뭉치와 대조하고, `doc_parity`가 결정 2·3과 "원문의 `///` 수 = 정규형에 남은 정의 요약 수"를 확인한다. 오라클과 약한 대조군은 주 조건에서 돈다.

## 근거

| 안 | 판정 |
| --- | --- |
| **정의 요약 대 `///`를 주 조건(채택)** | 두 팔이 같은 글을 본다. Rust 팔이 실제로 쓰이는 꼴에 가깝다. 주장에 "주석 없는" 한정이 붙지 않는다 |
| 지금대로(문서 없는 조건이 주) | 통로가 생긴 뒤에도 Rust 팔만 평소보다 불리한 조건이다 |
| Rust에 자유 주석까지(대조 조건을 주로) | BMB에는 자유 주석의 통로가 없다(DESIGN §4.1). 한쪽만 가진 정보가 판정에 든다 |
| Rust 쪽 `Requires`·`Ensures` 문장 금지 | BMB 팔은 그 내용을 계약으로 읽는다. 금지하면 Rust 팔만 사전 조건을 모른다 |

## 결과

- `bench/twin/pair.py`: `DOCS`(환경 변수 `PAIR_DOCS`), `strip_comments(.., docs)`, `strip_summaries`, `bmb_sources`, `item_docs`, 정의 수준 `doc_parity`. 결과 행의 `docs`가 조건을 적는다(`rust_comments`와 `PAIR_RUST_COMMENTS`는 없앤다: 쌍둥이의 정식 실행은 아직 없다).
- 포팅 쌍둥이의 고정 장치(3P-02)는 포트와 stage0에 같은 `///`를 단다. stage0(Rust)의 기존 문서 주석이 출발점이다.
- 3P-05의 사전 등록에 조건 셋과 결정 6을 넣는다.
