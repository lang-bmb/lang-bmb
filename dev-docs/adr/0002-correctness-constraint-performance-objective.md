# ADR-0002: 정확성은 제약, 성능은 목적함수

- 상태: 채택
- 날짜: 2026-10-24
- 관련: DESIGN.md §2, ADR-0001, genesis Q2·§3.4

## 맥락
v0는 "Performance > Everything"으로 출발했고, 검증은 끝까지 opt-in으로 남았다. 실측 결과 실제 코드 검증은 0/12였다.

## 결정
정확성은 만족하지 못하면 빌드하지 않는 **제약**이다. 성능은 그 제약 안에서 최대화하는 **목적함수**다.

## 근거
둘을 같은 층위의 우선순위로 두면 성능 압박이 검증을 밀어낸다. v0에서 실제로 그렇게 됐다. 제약과 목적함수로 나누면 성능 개선은 정확성을 깎을 수 없다.

## 결과
- 증명 게이트는 기본으로 켜지고 끌 수 없다(ADR-0003).
- v0의 성능 우위 주장은 무효로 보고 다시 잰다. 우위는 증명으로 검사를 지울 때만 정당하다(DESIGN.md 원칙 9).
