# ADR-0139: 측정 도구와 게이트 도구의 Python

- 상태: 채택(사람 승인 2026-11-14 "모두 권장안 채택", 백로그 `5D-03`)
- 날짜: 2026-11-14
- 관련: ADR-0021(벤치 동결), ADR-0037(부트스트랩), ADR-0039(지속 관리, §3 신뢰 기반), `dev-docs/HEALTH.md` §4(자립 사다리)

## 맥락

- ADR-0039는 벤치 하네스의 Python을 "언어 밖 측정 도구"로 두고 stage0 은퇴(4G) 뒤 다시 정하기로 했다. 그 결정을 미리 초안으로 낸다(승인 대기 시간을 앞당긴다).
- 지금 저장소의 Python은 129개 파일, 41,827줄이다(`scripts/`와 `bench/`). 쓰임은 셋이다.
  - **게이트 도구**(`scripts/`): 백로그·건강 지표·지문·구성 요소·적합성·차등 시험·진행 리포트.
  - **측정 하네스**(`bench/`): 모델 API 클라이언트, 세션 기록, 판정기, 결과 표.
  - **동결 집합의 생성기와 판정기**: MANIFEST가 그 파일의 SHA-256을 담는다(ADR-0021). 한 바이트가 바뀌면 집합을 다시 동결해야 하고 앞뒤 결과를 견줄 수 없다.
- 전부 표준 라이브러리만 쓴다(2026-11-14에 `import`를 세어 확인: 외부 패키지 0). Python의 버전은 고정돼 있지 않다(`scripts/toolchain.env`에 없다).
- 자립 사다리 L4는 "게이트·CI가 cargo 없이 돈다"이다. Python에 대해서는 말하지 않는다.

## 결정

1. **Python은 선언된 신뢰 기반으로 둔다.** Z3·clang·libc처럼 언어 밖의 도구다. BMB로 옮기는 것을 목표로 삼지 않는다. 자립의 주장(L0~L4)은 컴파일러와 그 게이트의 판정 경로에 대한 것이고, 측정 도구는 그 밖이다.
2. **조건 셋을 규칙으로 올린다.** 지금 지켜지고 있는 것을 게이트가 본다.
   - 표준 라이브러리만 쓴다(외부 패키지 0).
   - 버전을 `scripts/toolchain.env`에 고정하고 CI가 그 버전으로 돈다.
   - 스크립트마다 시험이 있고 게이트가 돌린다(지금의 `test_*.py`).
3. **동결 집합의 파일은 옮기지 않는다.** 생성기·판정기·하네스를 다른 언어로 다시 쓰면 ADR-0021의 재동결이고, 정식 결과가 있는 집합에서는 하지 않는다.
4. **판정 경로에 드는 도구는 4G 뒤 하나씩 다시 본다.** 컴파일러의 옳음을 판정하는 도구(차등 시험 `difftest.py`, 지문 `surface.py`, 구성 요소 고정 `components.py`)는 stage0이 은퇴하면 "Rust 없이 도는 게이트"의 일부다. 이것들을 BMB로 옮길지는 그때 실용성 점검(HEALTH §5)의 프로그램 후보로 본다: 옮기는 이유는 자립이 아니라 BMB로 쓴 실용 프로그램의 근거다.
5. **컴파일러는 Python을 실행하지 않는다.** S2(컴파일러가 실행하는 외부 프로세스)는 clang과 z3 그대로다.

## 근거

| 안 | 판정 |
| --- | --- |
| **신뢰 기반으로 선언하고 조건을 규칙으로(제안)** | 측정 도구는 가설을 재는 수단이지 언어의 일부가 아니다. 옮겨서 얻는 근거가 없고(어떤 가설도 재지 않는다), 동결 집합을 깨뜨린다. 조건 셋은 이미 지켜지고 있어 규칙으로 올리는 비용이 작다 |
| 전부 BMB로 옮긴다 | 4만 줄에 포팅 배율(포팅 지도 §7.3)을 곱한 양이다. 모델 API 클라이언트는 TLS와 HTTP가 필요해 런타임의 닫힌 내장 목록(ADR-0091)을 넓혀야 한다. 동결 집합의 MANIFEST가 모두 바뀐다 |
| 게이트 도구만 4G 직후 전부 옮긴다 | L4의 정의(cargo 없이)에 Python을 더하는 것이다. 자립의 주장을 넓히지만 그 주장을 요구하는 측정이나 사용자가 없다. 결정 4가 하나씩 여는 길을 남긴다 |
| 정하지 않는다 | ADR-0039가 4G 뒤로 미룬 그대로. 그 사이 외부 패키지가 들어오거나 버전이 갈려도 막는 규칙이 없다 |

## 결과

- 후속: 게이트의 외부 패키지 검사와 Python 버전 고정(백로그 `5D-04`).
- ADR-0039 §3의 표에서 "4G 뒤 재결정(5D-03)"을 이 ADR로 바꾼다.
- 열린 질문: 측정 머신과 CI의 Python 버전이 지금 같은지는 확인하지 않았다(고정 태스크에서 본다).
