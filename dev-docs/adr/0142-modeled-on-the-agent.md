# ADR-0142: 언어의 본은 에이전트의 작동 방식이다

- 상태: 채택 (사람 지시 2026-11-16: 결정 1~3의 굵은 문장. 그 아래의 풀이는 작성자의 해석이고 규약은 `T0-42`가 정한다)
- 날짜: 2026-11-16
- 관련: DESIGN.md §1·§2·§4, ADR-0001(사용자 = 에이전트), ADR-0040(전제 E3, H-FAMILIAR), ADR-0045(판단 기준), ADR-0100(동결), ADR-0111(가설 등급), 백로그 열일곱째 계획의 결정 기준, T0-38·T0-42

## 맥락

- 사람 지시(2026-11-16): "한글은 인간의 발음기관을 본떠 만들었다. AI의 언어는 AI의 작동 메커니즘을 본떠 만들어야 한다. 실측에 의한, AI 에이전트가 쓰고 싶은 언어를 만든다. 새 언어는 모델이 학습하지 않았다는 점을 감안해서 비교해야 한다."
- ADR-0001은 사용자를 에이전트로 정했지만 설계의 형태를 무엇에서 끌어오는지는 적지 않았다. "에이전트가 쓰고 싶은 언어"는 백로그의 열일곱째 계획에만 있었다(ADR-0141이 처음 적용).
- 측정에는 학습 여부가 섞여 있다. BRB(T0-10·T0-11)에서 BMB 대 Rust는 qwen 2/24 대 24/24, sonnet 21/24 대 24/24(토큰 15.6배)였고 모델 차이가 팔 차이보다 컸다(`dev-docs/measurements/t0-10.md` §6). 이 차이에서 설계의 몫과 학습 안 됨의 몫은 갈라지지 않았다(T0-38 보류).

## 결정

1. **설계의 본은 쓰는 쪽의 작동 방식이다.** 언어와 도구의 형태는 에이전트의 작동 방식 가운데 어느 성질에 맞춘 것인지로 정당화한다. 인간의 습관은 그 자체로는 근거가 아니다. 인간의 습관이 근거가 되는 길은 하나, 모델의 학습된 분포에 들어 있다는 사실이다.

   | 작동 방식의 성질 | 맞춘 설계 |
   | --- | --- |
   | 학습된 분포 위에서 쓴다 | 표면은 Rust·Verus 승계(DESIGN §4) |
   | 컨텍스트가 유한하고 세션 사이에 기억이 없다 | 맵, 슬라이스 예산, 코드에 묶인 근거(원칙 2·5·7) |
   | 출력은 확률적이고 실수가 섞인다 | 증명 게이트, 반례와 구조화된 진단(원칙 4·6·8) |
   | 같은 뜻을 여러 꼴로 낼 수 있다 | 표현과 정규형은 하나, 기계적으로 정해지는 표기는 도구가(원칙 6·8) |
   | 도구 호출로 읽고 쓴다 | 도구가 유일한 경로(원칙 6) |

   표는 대응이고 입증이 아니다. 입증 상태는 가설 등록부(ROADMAP)가 정본이다.

2. **"쓰고 싶다"는 실측으로 판정한다.** 에이전트의 자기 보고는 가설을 세우는 재료이고 근거가 아니다. 근거는 포팅 원장의 마찰(우회 수, 손으로 만든 보조 코드, 게이트 실행과 미결정 횟수, 세션 토큰)과 벤치의 성공률·토큰이다.

3. **비교는 학습 안 됨을 감안한다.** 학습된 언어와의 차이는 설계의 비용과 학습 안 됨의 비용의 합이다.
   - 둘을 가르지 않은 차이로 설계를 판정하지 않는다. 학습된 언어에 졌다는 결과만으로 기능을 빼거나 Rust 꼴로 되돌리지 않고, Rust 꼴이라는 이유만으로 채택하지도 않는다.
   - 설계 결정의 1순위 근거는 두 팔이 똑같이 낯선 비교다: BMB의 판 대 판(절제 측정), 같은 정도로 낯선 대조(Verus).
   - 학습된 언어와의 비교는 가르지 않은 값(지금 모델에서의 실제 손익, 전제 E3의 판정)과 가른 값을 따로 보고한다. 가르는 수단의 규약은 `T0-42`가 정한다.

## 근거

- 표면 승계는 이 결정의 예외가 아니라 첫 적용이다: 학습된 분포도 작동 방식이다. 다만 승계는 공리에서 가설(H-FAMILIAR)로 내려온다. 가른 측정이 다른 꼴을 가리키면 그 꼴이 이긴다.
- 자기 보고를 근거에서 뺀 이유: 운영 규칙(주장은 코드 경로와 측정으로)과 같고, 에이전트의 선호 진술은 재현되지 않는다.
- 전제 E3은 학습 안 됨의 비용을 치르는 값에 넣었다. 그 판정(지금의 손익)은 그대로 두고, 설계 판단에 쓰는 값만 가른다. 둘을 한 숫자로 섞으면 일시 비용 때문에 맞는 설계를 버리거나, 설계의 결함을 일시 비용이라 부르게 된다.

## 결과

- 받아들이는 언어를 바꾸는 수정은 여전히 ADR-0100의 예외 절차와 사람 승인을 거친다. 이 결정은 안건의 방향과 근거의 종류를 정한다.
- JUDGMENT §7에 판단 질문 둘을 더한다. 새 기능·표면의 ADR은 맞춘 성질과 실측 근거를 적는다.
- 가르는 측정에는 모델 실행이 든다. `T0-42`는 규약만 정하고 실행은 대기열과 승인을 따른다. T0-38(미세조정 팔)의 보류는 그대로다.
