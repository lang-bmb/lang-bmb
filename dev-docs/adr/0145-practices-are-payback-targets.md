# ADR-0145: 개발 관행도 대가 회수의 대상이다

- 상태: 제안 (2026-11-22, 사람의 방향: "언어·문법·컴파일러·도구 수준을 넘어 개발 관행·패턴에 대해서도 의심하고 회수한다. 새로운 개발 패러다임을 열 가능성을 충분히 탐색한다")
- 날짜: 2026-11-22
- 관련: DESIGN.md §4.1·§8·§9, ADR-0041(트레이드오프 원장), ADR-0059(정체성 해시), ADR-0060(타입 불변식), ADR-0065(교환 관계), ADR-0102(수명 단위), ADR-0142(본은 에이전트의 작동 방식), `dev-docs/reviews/practices-2026-11-22.md`, `dev-docs/reviews/collaboration-2026-10-28.md`, 백로그 `4E-03`

## 맥락

- DESIGN §4.1과 §8은 Rust·Verus가 인간의 편의 때문에 남긴 것을 포기하고 그 대가를 컴파일러와 도구에서 회수한다. 회수의 목록은 거기서 끝난다.
- 브랜치·PR·병합 큐, 변경마다 도는 CI, 버전 번호, 재시작하는 배포, 카나리와 롤백은 언어가 주지 못하는 성질을 메우는 관행이다: 두 편집의 독립, 변경의 영향 범위, 새 판이 옛 약속을 지키는지, 새 코드가 돌던 상태와 맞는지.
- BMB에는 그 성질의 여럿이 이미 있다: 읽기 집합(증분 증명 키), 교환 판정(ADR-0065, 건전성 위반 0), 계약 변경의 방향(`bmb weaken`, 483/483), 계약 방화벽, 내용으로 정해지는 정체성, 전역 가변 상태 없음, 타입에 붙은 불변식. 관행 쪽의 회수는 설계에도 가설 등록부에도 없다(협업 논의는 H-COMMUTE·H-SPLIT까지 갔다).
- 불리한 근거도 있다. `3P-05a`: 정의의 글을 읽는 질문과 리팩터링에서 BMB 팔이 Rust 팔보다 많이 쓴다. 관행의 회수는 편집 한 번의 비용을 줄이지 않는다.

## 결정

1. **개발 관행을 대가 회수의 대상으로 둔다.** DESIGN §8에 "관행 레벨" 표를 더한다: 관행, 그것이 메우는 결핍, 그 결핍을 없애는 BMB의 성질, 회수한 꼴, 근거의 상태. 근거가 없는 줄은 "미측정"으로 적고 주장하지 않는다. DESIGN §9에 열린 연구 R5 "협업과 배포의 기반"을 더한다.
2. **가설 셋을 등록한다.** H-TRUNK(줄기 하나에 정의 단위로 동시에 커밋하는 방식이 브랜치로 나눠 합치는 방식보다 통합의 검증 비용이 작고 통합 실패가 0이다), H-LIVE(정제로 증명된 정의 교체는 재시작 없이 적용해도 관측 행동이 옛 계약 안에 머물고, 실제 편집의 과반이 그런 교체다), H-RACE(같은 계약의 경쟁 구현에서 증명된 것 가운데 측정으로 고르면 성능이 좋고 수명 단위 총 토큰이 같거나 적다). 반증 조건은 검토 문서 §8.
3. **판정과 상한을 먼저 잰다. 기구는 짓지 않는다.** 동시 커밋을 받는 서버, 돌고 있는 프로그램의 정의를 바꾸는 런타임, 경쟁 구현의 조정기는 결정론 실험(실제 이력의 편집의 꼴, 줄기의 처리량 재생)이 상한을 보인 뒤에 따로 결정한다.
4. **순서.** 이 탐색은 관문 B와 P5 이후의 포팅보다 앞서지 않는다. 결정론 실험은 그것들과 나란히 돈다.

## 근거

| 안 | 판정 |
| --- | --- |
| **관행을 원장에 넣고 가설로 잰다(권장)** | 회수의 근거가 되는 성질이 이미 있고 일부는 재어졌다. 원장에 없으면 관행은 "언어 밖"으로 남아 회수되지 않는다. 가설로 두면 반증될 수 있다 |
| 기구(서버, 교체 런타임)부터 짓는다 | 운영 규칙에 어긋난다(차별점 가설은 그 위에 쌓기 전에 최소 실험으로 측정한다). 닫힌 세계 최적화·런타임 의존 최저(ADR-0041)와 부딪치는 결정을 근거 없이 하게 된다 |
| 언어 밖으로 둔다(지금의 상태) | 협업 논의의 권장이었다(서버는 제품 결정). 판정은 그대로 옳다. 그러나 무엇을 회수할 수 있는지의 목록과 가설까지 밖에 두면 탐색 자체가 일어나지 않는다 |

- 회수는 증명되는 것에만 선다. `io` 껍데기, 성능, 자원, 코드 밖 구성에는 관행이 그대로 남는다(DESIGN §3 보장 범위 밖).
