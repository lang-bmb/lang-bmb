# ADR-0005: 언어의 책임은 코드와 맵까지

- 상태: 채택
- 날짜: 2026-10-24
- 관련: DESIGN.md §1, ADR-0004, ADR-0007, genesis Q4'

## 맥락
설계서를 도출한다면(ADR-0004), 인간이 읽기 좋은 설계서와 도식까지 언어가 책임져야 하는가.

## 결정
언어의 책임 범위는 **코드와 맵**까지다. 인간용 설계서·도식은 맵을 소비하는 언어 밖 도구가 맡는다. 그 도구도 직접 만든다.

## 근거
맵은 에이전트의 탐색용이고, 인간용 설계서와는 다른 물건이다. 둘을 한 산출물로 묶으면 맵이 커지고, 맵을 작게 유지한다는 원칙(ADR-0008)과 충돌한다.

## 결과
맵은 서드파티(설계서 도구 포함)가 의존할 수 있는 안정된 계약이어야 한다(ADR-0008).
