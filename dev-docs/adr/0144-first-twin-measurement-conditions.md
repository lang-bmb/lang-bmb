# ADR-0144: 포팅 쌍둥이 첫 측정의 조건

- 상태: 채택 (사람 승인 2026-11-17 "권장안 채택, 모델 실행 승인, 자율 실행/검증 승인": 결정 1·2·3은 그 권장안, 결정 4는 태스크 분해)
- 날짜: 2026-11-17
- 관련: ADR-0021(동결), ADR-0068(압축 뷰), ADR-0101(정식 쓰기 표면), ADR-0104(포팅 쌍둥이), ADR-0106·0118(문서 조건), 백로그 3P-02·3P-03·3P-05·3P-10

## 맥락

과제 집합(이해 24, 리팩터링 21)을 처음 끝까지 돌리자 측정 전에 정할 것이 넷 드러났다.

- **쓰기 응답.** `bmb mcp --write-tool`의 `write`는 작업 공간의 정의마다 상태 줄을 돌려준다. 포트(정의 1,515개)에서 쓰기 한 번의 응답이 약 4만 토큰이다. 이름 바꾸기 기준 해법이 BMB 팔 82,441토큰, Rust 팔 9토큰이다(3P-10). 그대로 재면 BMB 팔의 토큰은 바꾼 양이 아니라 이 줄들이 정한다.
- **문서.** 포트의 정의 요약은 한국어이고 stage0의 `///`는 영어다. ADR-0118의 주 조건(`summary`)이 전제하는 "같은 글"이 성립하지 않는다.
- **글 찾기.** Rust 팔에는 `grep`이 있고 BMB 팔에는 본문의 글을 찾는 도구가 없다. 진단 코드와 필드 이름으로 묻는 갈래(`diag`, `state`)는 이 차이를 직접 잰다.
- **재연 과제.** 커밋 재연(3P-04)은 과제마다 두 쪽의 되돌린 상태를 손으로 만들어야 해서 나머지 두 축보다 늦다.

## 결정

1. **BMB 팔의 서버는 `bmb mcp --write-tool --compact`다.** 증명 결과(`write`·`verify`·`build`)는 진단과 실패한 정의의 상태 줄, 그리고 증명된 정의의 수 한 줄이다(ADR-0068 결정 1). 읽기 결과도 같은 플래그의 압축 뷰로 나온다. 컴파일러는 바꾸지 않는다. 하네스의 `PAIR_MCP`가 플래그를 정하고 결과 행의 `mcp`가 적는다.
2. **포팅 쌍둥이의 주 문서 조건은 `none`이다.** 두 팔 모두 정의 문서가 없다(BMB는 정의의 `#[summary]` 줄, Rust는 `//!`를 뺀 모든 주석). 주석 있는 Rust 대조(`all`, Rust 팔만, sonnet 1회, ADR-0106 결정 2)는 그대로 돈다. `stk` 고정 장치의 주 조건은 `summary` 그대로다.
3. **과제는 그대로 두고 갈래별로 보고한다.** `diag`·`state` 갈래를 빼거나 BMB 팔에 글 찾기를 더하지 않는다. 축의 판정은 전체로 하고, 표에 갈래별 값을 나란히 싣는다.
4. **첫 측정을 둘로 나눈다.** `3P-05a`는 이해와 리팩터링, `3P-05b`는 커밋 재연이다. 집합마다 첫 실행 전에 동결한다.

## 근거

| 안 | 판정 |
| --- | --- |
| **`--compact`(채택)** | 이미 있는 플래그이고 응답 꼴이 3P-10이 바라던 것과 같다(실패한 정의와 셈 하나). 새 표면이 없다 |
| 쓰기 응답만 줄이는 새 플래그 | 같은 일을 하는 플래그가 둘이 된다(ADR-0120). 압축 뷰의 읽기 결과를 빼야 할 근거가 없다 |
| 지금 꼴로 잰다 | 토큰 비교가 응답 형식을 잰다. 가설(H-REFACTOR의 총 토큰)이 묻는 것이 아니다 |

- 압축 뷰가 성공률을 낮추지 않는지는 아직 재지 않았다(T0-15). 이 측정은 기본값 전환의 근거가 아니고, 결과는 플래그와 함께 보고한다.
- `none`은 Rust 팔에서 정보를 빼는 쪽의 조건이다. 그 치우침의 크기는 `all` 대조가 잰다.
- 글 찾기의 차이는 도구 표면의 실제 차이다. 과제를 고르면 측정이 그 차이를 감춘다. 갈래별 값이 있으면 차이가 어디서 오는지 읽을 수 있다.

## 결과

- `bench/twin/pair.py`의 `mcp_flags`, `bench/twin/README.md`의 조건 표.
- 리팩터링 과제의 Rust 기준 해법(`edit_file`의 `old`)은 `none` 조건의 글에 맞춰 만든다.
- 백로그: `3P-10` 닫음, `3P-05`를 `3P-05a`·`3P-05b`로.
- BMB 팔에 본문의 글 찾기가 필요한지는 `3P-05a`의 갈래별 결과로 정한다.
