# ADR-0006: 근거는 노드 해시에 묶어 코드 안에

- 상태: 채택
- 날짜: 2026-10-24
- 관련: DESIGN.md 원칙 3, §4.1(주석), genesis Q5

## 맥락
"왜 이렇게 했나"(근거)를 어디에 둘 것인가. 외부 ADR이나 자유 주석은 코드가 바뀌어도 그대로 남는다.

## 결정
코드 수준의 근거는 **노드 해시에 묶인 구조화 선언**으로 코드 안에 둔다. 묶인 노드가 바뀌면 그 근거는 "미확인"으로 표시된다.

## 근거
외부 문서로 두면 어긋나고, 어긋났는지도 알 수 없다. 해시에 묶으면 어긋남이 기계적으로 감지된다.

## 결과
- 자유 텍스트 주석은 언어에서 구조화 근거로 대체된다(DESIGN.md §4.1).
- 근거 문법은 Rust에 대응물이 없는 몇 안 되는 새 구문이다.
- 이 ADR 디렉터리는 언어 *설계*의 결정 기록이며, BMB 코드의 근거와는 다른 층위다.
