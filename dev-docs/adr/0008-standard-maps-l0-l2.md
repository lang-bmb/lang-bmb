# ADR-0008: 표준 맵 L0~L2 고정, 추가는 하위 호환

- 상태: 채택
- 날짜: 2026-10-24
- 관련: DESIGN.md 원칙 2, §7, genesis Q7

## 맥락
맵을 어디까지 명세에 넣을 것인가. 서드파티 도구가 의존하려면 고정된 계약이 필요하지만, 너무 많이 고정하면 진화할 수 없다.

## 결정
- 표준 탐색 맵 **L0(목차)·L1(표면)·L2(관계)**를 명세에 고정한다.
- 이후 수준 추가는 하위 호환으로만 허용한다.
- 나머지 관점은 확장 맵으로 둔다.
- 맵은 코드를 담지 않고 위치와 해시로 가리킨다.

## 근거
서드파티 도구가 의존할 계약이 필요하다. 맵은 탐색에 필요한 것만 담고 작게 유지한다.

## 결과
v0의 `bmb index`가 가졌던 비결정 요소(시각 기록, 미정렬 목록)는 허용되지 않는다. 같은 코드면 바이트 단위로 같은 맵이 나와야 한다.
