# ADR-0003: 테스트 필요 면적의 산출·최소화

- 상태: 채택
- 날짜: 2026-10-24
- 관련: DESIGN.md 원칙 4, genesis Q3

## 맥락
착수 서술의 "테스트 코드를 거의 쓰지 않는다"를 원칙으로 옮겨야 했다. "테스트 0"은 IO 같은 외부 경계 때문에 문자 그대로는 거짓이다.

## 결정
원칙은 "증명이 테스트를 대체한다"로 쓴다. 테스트가 필요한 면적은 **컴파일러가 산출하고 최소화**한다. "테스트 0"은 지향점으로만 둔다.

## 근거
외부 경계(IO, 시간, 난수 등)는 증명 범위 밖이다. 측정할 수 있고 과장이 없는 표현을 택했다.

## 결과
- 효과 시스템이 필요하다. 테스트 필요 면적을 산출하는 근거가 효과 선언이다.
- 미증명 면적과 테스트 필요 면적은 맵에 집계되고, 측정 축이 된다(DESIGN.md §9 R4).
