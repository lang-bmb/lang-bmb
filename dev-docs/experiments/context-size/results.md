## 4. 마지막 요청의 문맥 분해(파일럿, 세션 평균)

마지막 요청의 입력은 고정 부분과 그때까지의 모든 도구 결과·호출 인자·모델 출력이다(문맥의 최댓값, 64K 한도와 견줄 값). "실측"은 CLI가 보고한 마지막 요청의 입력 토큰(캐시 포함), 나머지는 추정 토큰이다. "나머지" = 실측 − 고정 − 도구 결과 − 호출 인자: 모델의 글·사고와 CLI가 덧붙이는 틀. `--compact` 열은 같은 호출의 결과를 `--compact`로 바꾸고 도구 설명이 늘어난 만큼을 더한 값이다.

## 5. 정식 측정(qwen3.8-27b, 커밋 `8d569693`)의 요청당 문맥

하네스는 세션의 요청 수와 프롬프트 토큰 합을 남긴다(`model_usage`). 요청별 값과 호출별 결과 크기는 남기지 않는다. 그래서 요청당 평균은 정확하고, 마지막 요청은 하한(고정 + 읽기 결과)만 낸다. 고정 부분의 qwen 토큰은 `w08-digits`(m1, 첫 요청에서 출력 한도로 끝나 요청이 하나)의 2,291토큰으로 맞췄다. 읽기 결과의 qwen 토큰은 파일럿 재실행의 바이트당 추정 토큰을 같은 비로 줄인 값이다.

qwen/추정 비 0.79(고정 부분), 읽기 결과 바이트당 추정 토큰 0.516, 재실행에서 읽기 결과의 `--compact`/기본 토큰 비 0.24.

| 집합 | 세션 | 요청 | 요청당 프롬프트 토큰(평균) | 세션 평균의 최댓값 | 고정(qwen) | 고정의 몫 | 읽기 바이트(세션 평균) | 마지막 요청 하한(최대) | 같은 하한, `--compact` | 끝남: 출력 한도 / 호출 한도 / `api_error` |

| m1b | 37 | 466 | 14,207 | 47,733 | 2,321 | 16% | 27,843 | 40,150 | 11,434 | 1 / 5 / 0 |
