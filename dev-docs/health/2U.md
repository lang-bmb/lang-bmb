## 실용성 (HEALTH.md §5)

- 실행 프로그램은 위 기준 3. 증명이 두 프로그램의 실제 결함을 찾았다: 끝 낱말 뒤에서 인덱스가 길이를 넘는 것(`strings::words`, 반례 `t = [31, 31]`), 사전조건 없는 `hex`의 `48 + d` 넘침(`escape::hex`).
- 마찰: `dev-docs/measurements/m1.md` §6에 2U 행 다섯, 처리 칸 모두 채움. 셋은 유지(바이트에서 글자 만들기의 길이, 덧붙이기의 길이 의무, 정규형이 주석을 지움), 둘은 백로그(2U-06 UTF-8 불변식 사실, 2U-07 문자열 표준 연산).
- 발견해 고친 것: 거짓인 루프 불변식에서 Z3가 반례를 만들지 못하고 "incomplete (theory array)"로 끝나는 질의(`lambda` 배열을 선언 함수 `bmb_shift`로, 비상수 `char`의 `push`를 바이트 갈래로), 길이 의무를 바이트 사실보다 먼저 내 반례가 rlimit 5,000,163의 미결정에서 2,118의 반례로, 공통 CLI 실행기(`common::cli::run`)가 하위 디렉터리 이름을 쓰지 못하던 것.
- 남은 일(이 페이즈를 막지 않음): 2U-06, 2U-07, ADR-0050 열린 질문 1(명세의 문자 보기 `Seq<char>`, 수요가 나올 때).
