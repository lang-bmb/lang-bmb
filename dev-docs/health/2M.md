## 실용성 (HEALTH.md §5)

- 실행 프로그램은 위 기준 3.
- 마찰: `dev-docs/measurements/m1.md` §6에 2M 행 셋. 둘은 유지(자기 타입 매개변수가 있는 함수는 경로 호출, `&T`를 `&mut self`에 넘기지 못함: Rust와 같음), 하나는 백로그 2T-09(trait의 `Self`가 `Copy`여야 해서 `Vec`을 담은 타입이 trait을 구현하지 못한다: 검사기가 `Self`에 붙인 경계로 ADR-0046에 없던 제한, 4B 표준 라이브러리가 부딪힌다).
- 발견해 고친 것: 작업 공간 `rename`이 메서드 호출 지점을 바꾸지 않아 메서드 이름 바꾸기가 거부되던 것(`refs::Rewrite::method`), `bmb weaken`이 메서드 호출이 있는 계약을 한 프로그램으로 맞추지 못하던 것(옛 판을 경로 호출로 쓴다), MCP `edit_ast`의 되읽기 비교가 정규형의 메서드 호출을 차이로 보던 것.
- 남은 일(이 페이즈를 막지 않음): 2T-09, 메서드 타입 인자 구문(빈도가 나오면), ADR-0091 열린 질문 1(`io::Error`의 메서드, 4C-02 (e)와 함께).
