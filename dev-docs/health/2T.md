## 실용성 (HEALTH.md §5)

- 실행 프로그램은 위 기준 3. 고정 용량 스택(`generic_stack`)은 `push`·`pop`의 정확한 계약(`pushed`·`popped`)으로 괄호 검사까지 증명된다.
- 마찰: `dev-docs/measurements/m1.md` §6에 2T 행 5개(무한 정수 명세와 `i64` 술어 가드, 구조체 생성 식의 `Self` 추론, 정수 타입의 `&self` impl, `i64::MIN`, 경계 재귀), 처리 칸 모두 채움. 셋은 고쳤다(`place_peek`, ADR-0054, 2N-06).
- 발견해 고친 것: 제네릭 `&T`의 스칼라 인스턴스에서 코드 생성 패닉(2T-01부터, 2T-08), 2T-02 뒤 적용되지 않던 게이트 검출력 변이체 여섯(게이트 단계 `power` 추가), 기본 spec 본문 공개의 과잉 보수(`Self = Wrap<T>`).
- 남은 결정: 경계 `Self` 호출을 거치는 재귀는 E0207(측도 없음, ADR-0046 §4). 실제 사용에서 필요해지면 trait 메서드 측도를 설계한다.
