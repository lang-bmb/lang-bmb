# 문법 대안 오프라인 비교 (2R-04)

> 백로그 2R-04(하위 2R-04a~h). 1차 평가(`syntax-eval-1.md` §5)의 상위 후보마다 대안 문법을 정하고, 모델 없이 결정론적으로 잴 수 있는 것을 잰다. 실제 모델 근거는 2R-03·2R-05가 더하고, 문법 결정은 2R-06(승인)이 한다. 저울은 ADR-0036.

## 2R-04d: 2B 표면(I3·I7)

**대안.** ADR-0026 정본(`canon`)에 세 가지를 차례로 얹었다(`bench/syntax/surface2b.py`).

| 변형 | 바꾸는 것 |
| --- | --- |
| `prelude` | `Option::Some(x)`·`Option::None`·`Result::Ok(x)`·`Result::Err(e)` → `Some(x)`·`None`·`Ok(x)`·`Err(e)`. 사용자 열거형은 `E::V` 그대로 |
| `self` | `impl` 함수의 첫 매개변수 `p: &T` → `self: &T`(`&mut`도) |
| `method` | `prelude` + `self` 위에서 `T::f(&x, ..)` → `x.f(..)`. 정본은 경로 호출로 되돌린다 |

**코퍼스.** ADR-0026 예시와 2B 과제 후보로 쓴 초안 6개(기하, 도형 넓이, `Option`을 돌려주는 검색, `Result`를 돌려주는 검증, 크기 고정 스택, 상태 기계). 2B 구현 전이라 검사·증명은 하지 않고 어휘 토큰만 센다(`bench/syntax/measure.py`의 `lex`).

**측정(2026-10-25).**

| 프로그램 | canon | prelude | self | method |
| --- | ---: | ---: | ---: | ---: |
| geometry | 324 | 324 | 324 | 322 |
| shapes | 342 | 342 | 342 | 340 |
| search | 366 | 340 | 366 | 340 |
| validate | 298 | 270 | 298 | 270 |
| stack | 395 | 385 | 395 | 378 |
| machine | 480 | 450 | 480 | 447 |
| 합 | 2,205 | 2,111(−4.3%) | 2,205(±0) | 2,097(−4.9%) |

- **prelude 이름 예약.** 저장소의 BMB 코드와 벤치 과제 해법(기준·약한 대조군)에서 `Some`·`None`·`Ok`·`Err`라는 이름의 정의는 없다. 예약해도 바뀌는 기존 이름이 없다. 이 이름들은 `print_i64`처럼 내장이라 해석 모호성이 없다(K2·K3 유지).
- **`self: &T`.** 토큰은 같다(이름만 바뀜). 유효한 Rust이고 Rust 습관 `&self`에 가장 가까운 명시 형태다. 타입이 적혀 있어 슬라이스 자급(모든 매개변수 타입 명시)도 그대로다.
- **메서드 호출.** prelude 위에 0.6%를 더 줄인다. 코퍼스의 수신자 7개는 모두 매개변수나 지역 변수다. BMB는 모든 지역·매개변수 타입을 적게 하므로 그 정의의 원문만으로 대상 타입이 정해진다. 필드 투영(`a.b.f()`)이면 구조체 선언이, 호출 결과(`g().f()`)면 피호출자 시그니처가 정한다. 셋 다 추론 없이 검사기가 정한다. 다만 슬라이스 안에서 구문만으로 정해지는 것은 첫째뿐이다. 그래서 정본은 경로 호출로 둔다(K3).

**권고(2B-11의 입력).**

| 구성 | 권고 | 근거 |
| --- | --- | --- |
| I3 `Option`·`Result` 변형 | **차용**: 정본은 `Some`·`None`·`Ok`·`Err`. `Option::Some` 등은 입력 별칭으로 받아 정본으로 옮긴다 | −4.3% 토큰(`Option`·`Result`를 쓰는 프로그램 4개에서 −2.5~−9.4%), 예약 충돌 없음, Rust prelude 습관(C1) |
| I7 수신자 | **변형 유지, 형태 교체**: 정본은 `fn f(self: &T)`. `&self`·`&mut self`는 입력 별칭 | 토큰 같음, 유효 Rust, 명시 타입 유지 |
| I7 호출 | **변형 유지 + 입력 별칭**: 정본은 `T::f(&x)`. `x.f()`는 검사기가 대상을 정해 정본으로 옮긴다 | 구문만으로 간선이 정해지는 성질(K3)은 정본에 있다. 별칭의 대상 결정은 언제나 가능하다(모든 타입 명시) |

**반영(2B-11).** ADR-0026 채택은 앞의 둘(내장 변형 맨이름, `self: &T`)을 반영했다. 셋째(메서드 호출 입력 별칭)는 습관 형태를 오류 없이 받는 쓰기 표면 정책의 변경이라 2R-04e·2R-06(승인)으로 넘겼고, 그때까지는 거부와 기계적 수정이다.

**한계.** 코퍼스는 우리가 쓴 초안 6개다. 2B 과제(2B-10)가 생기면 같은 스크립트로 다시 잰다. 수신자가 필드·호출 결과인 경우가 코퍼스에 없다.
