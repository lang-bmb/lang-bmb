## 읽기

- **등록 규칙으로 반증이다**: 반례와 수정 제안이 있는 쪽의 수리 반복(성공 작성 세션당 거부 커밋 + 실패 증명)이 절제 판보다 적지 않고 오히려 많다.
- 차이의 대부분은 과제 하나다. `w01-all-in-range`가 전체 판에서 거부 7·실패 증명 2, 절제 판에서 0·0이다. 이 과제를 빼면 전체 (19+1)/22 = 0.91, 절제 0.88로 거의 같다. 반복 지표의 실행 간 변동은 재지 않았다(T0-12는 성공률만 반복했다). 그래서 "반례·`fix`가 반복을 늘린다"는 주장도 이 한 번으로는 하지 않는다. 주장할 수 있는 것은 "40% 감소는 이 실행에서 나타나지 않았다"이다.
- 성공률 23/25 대 24/25는 최소 차이 D = 30%p(T0-12) 안이다.
