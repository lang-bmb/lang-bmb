# 문법 구성별 측정 근거 (2R-03)

> 백로그 2R-03. 2026-11-08. 실제 모델 실행(정식 경로 ADR-0066)의 세션 기록에서, 구성마다 모델이 쓴 Rust·Verus·Dafny 습관과 그 진단을 센다. 새 모델 실행은 없다. 하네스 `bench/syntax/evidence.py`, 원자료 `dev-docs/measurements/syntax-uses/evidence-2026-11-08.jsonl`. 2R-02(`syntax-eval-1.md`)의 1차 평가와 2R-04(`syntax-eval-2.md`)의 오프라인 비교에 이어 2R-06(문법 결정)의 입력이다.

## 자료

- 동결된 하네스가 남긴 세션 기록 `bench/*/results/**/*.sessions/*.json.gz` 가운데 BMB 쪽 1,205개(Rust·Verus 대조 팔은 뺌). 벤치 m1, m1b(와 `-write`·`-diff`·`-ast`·`-alpha`·`-mislead`·`-write-norepair` 변형, 반복 5회), BRB(4종), BVB(4종), 2026-10-31 ~ 11-06. 모델 `qwen3.8-27b`(기본)와 `claude-sonnet-5-5`(교차 비교).
- 토큰 159,952,776(요청의 입력+출력).
- **진단**: 도구가 에이전트에게 돌려준 결과 속 진단 코드. 세션마다 "나온 적 있음", "첫 진단 결과에 있음"(첫 시도), "마지막 진단 결과에 있음"(에이전트가 끝낸 시도)을 센다.
- **습관**: 에이전트가 보낸 코드(`tx_put`·`write`)를 습관 꼴의 정규식에 맞춘다. E0103(일반 구문 오류)이 여러 습관을 한 코드로 담기 때문이다.

## 읽기

1. **가장 큰 마찰은 루프·계약 절의 꼴이다.** 절 키워드 되풀이(20%)와 몸 안의 불변식(12%)은 뜻이 분명한 다른 꼴이고 기계로 정본에 옮길 수 있는데 지금은 수정 없는 E0103이다. 둘 다 거의 qwen이다(sonnet은 1세션). 2R-06 입력: 받아서 정본으로 고치는 E02xx 수정(습관 입력 → 정본, 2R-04e의 규칙과 같은 꼴), 정본은 그대로.
2. **계약 절의 인라인 식(17%, E0501 245세션)은 2R-04b의 권고 T2를 뒷받침한다.** qwen이 대부분이다.
3. **`decreases` 없는 `while`(12%)은 증명 게이트의 규칙이다**(원칙: 종료를 증명한다). 꼴의 문제가 아니므로 문법 결정의 대상이 아니다. 안내를 `for`(2R-04f) 쪽으로 돌리는 것이 도구 개선이다.
4. **셰도잉(E0303, 152세션, 끝까지 남은 73)은 BMB만의 규칙이다**(Rust는 허용). 이 세션의 구현 작업에서도 같은 이름을 형제 범위의 `match` 바인딩이나 다른 `let`에 다시 쓸 때마다 걸렸다. 2R-06 입력: 겹치지 않는 범위의 같은 이름은 허용하고 진짜 가림(안쪽 범위가 바깥 이름을 가림)만 거부할지.
5. **Verus 명세 별칭은 작다.** `exists`·`T::MAX`는 이미 받고, `int`·`nat`는 0.5%, `@` 보기는 0이다(2R-04g).
6. **복합 대입(`+=`)은 0.2%다.** 2N-07(승인 대기)의 측정 근거는 약하다(시드·기준 해법 쪽의 근거 D6은 별개).

## 한계

- 세션은 같은 과제를 되풀이한다(반복 5회 포함). 비율은 세션 단위이고 과제 단위가 아니다.
- 습관 정규식은 근사다(특히 셰도잉). 진단 집계는 도구가 실제로 돌려준 것이라 정확하다.
- 모델 둘 중 습관의 대부분은 qwen이다. sonnet의 습관은 `as`·`exists`·E0511이 크다.
