### 읽기(sonnet)

- **반증(sonnet)**: 두 팔 모두 4/4이고, 등록 규칙(README)의 두 조건을 모두 넘는다. 남은 테스트 면적 4/6 = 0.667(기준 ≤ 0.20), BMB 남은 면적의 줄 169 대 Rust 에이전트 테스트 41줄 = 4.12배(기준 ≤ 1/3).
- 보조 지표: 기준 해법 면적 0.211의 3.17배다. 에이전트는 기준 해법보다 덜 나눴다(실행 정의 6개 대 기준 19개). 출력 껍데기가 과제마다 하나 이상이라 정의가 적을수록 면적이 커진다(README "미리 알려 둘 것").
- Rust 쪽 테스트가 41줄로 qwen(679줄)보다 훨씬 적다. 줄 조건의 분모가 모델마다 크게 다르다는 뜻이고, 이 조건은 Rust 에이전트가 테스트를 얼마나 쓰는지에 좌우된다.
- **H-EFFECT 판정:** README의 판정은 모델마다다(두 조건 중 하나라도 넘으면 그 모델에서 반증). 확정은 두 모델 모두 충족일 때다. qwen은 판정 불가, sonnet은 반증이므로 이 집합에서 H-EFFECT는 **sonnet에서 반증, 확정될 수 없음**이다.
- 귀속(정보): 면적은 효과 체계가 아니라 분해에서 온다. 에이전트가 껍데기와 핵심을 나눠도 껍데기 자체(출력 정의)가 남은 테스트 면적이다. 이 집합의 과제 크기에서는 기준 해법도 기준을 넘으므로, 효과로 드러낸 껍데기가 "작다"는 주장은 이 크기의 과제에서 성립하지 않는다.
