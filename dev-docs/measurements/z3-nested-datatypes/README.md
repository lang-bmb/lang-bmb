# Z3와 배열에 중첩된 데이터타입 (백로그 2O-03c·2O-03d)

`Vec`을 거친 재귀 열거형(`enum Tree { Leaf(i64), Many(Vec<Tree>) }`)은 증명에서 원소 배열이 그 데이터타입인 필드를 가진다(`(Array Int |Tree|)`, Z3의 중첩 데이터타입). 2O-03c를 구현하며 만족 가능한 질의 하나가 끝나지 않는 것을 보았다.

- `hang.smt2`: 증명기가 낸 질의 그대로(`tests/verify/fail/vec_recursion.bmb`의 `two`, `+` 넘침 의무). Z3 4.15.4(`scripts/toolchain.env`)가 20초 안에 답하지 않고 `rlimit 5000000`에서도 멈추지 않는다(증명기는 `-T 360`까지 기다린다).
- `ok.smt2`: 같은 질의에서 데이터타입 선언만 서곡(`bmb_abs`·`bmb_tdiv`·`bmb_trem` 정의) 앞으로 옮긴 것. 즉시 `sat`.

| 질의 | 결과 | 시간 |
| --- | --- | --- |
| `hang.smt2` | 답 없음 | 20초 제한에 걸림 |
| `ok.smt2` | `sat` | 0.03초 |

정의 하나씩 빼 보면 `bmb_tdiv`·`bmb_trem`(정수 `div`를 쓰는 매크로)이 있을 때만 걸리고, 데이터타입을 그 앞에 두면 걸리지 않는다. 시드 1~4에서도 같다.

조치(`verify::needed_decls`): 모든 질의에서 데이터타입 선언을 서곡 앞에 둔다. 데이터타입은 서곡을 쓰지 않으므로 의미는 같다. 증분 키의 질의 머리(`query_header`)는 서곡을 계속 포함한다.

재현: `z3 hang.smt2`(걸림), `z3 ok.smt2`(`sat`).

## 구조체만으로 된 재귀 (백로그 2O-03d)

`struct Node { v: i64, kids: Vec<Node> }`는 열거형처럼 생성자가 여럿이 아니므로, 데이터타입으로 두면 유일한 생성자가 자기 배열을 담는다. Z3는 그런 데이터타입을 받지 않아(`datatype is not well-founded`) 자리 채움 생성자를 하나 더한 것이 첫 인코딩이다. 세 인코딩을 증명기가 낸 질의로 쟀다.

| 질의 | 인코딩 | 결과 | 시간 |
| --- | --- | --- | --- |
| `struct-datatype.smt2` | 데이터타입 + 자리 채움 생성자(`rose::adopt`) | 답 없음 | 20초 제한에 걸림 |
| `struct-sort.smt2` | 정해지지 않은 정렬, 선택자 함수(`rf::relabel`, 한정자 spec fn 정의 포함) | `unknown`, rlimit 5000314(한도) | 1.65초 |
| `struct-int.smt2` | 같은 질의, 정렬을 `Int`로(`define-sort`) | `sat`, rlimit 93293 | 0.09초 |

데이터타입은 자리 채움 생성자의 위치·모양을 바꿔도 작은 만족 질의(원소 하나의 필드를 묻는 것)에서 걸리거나(20초) 한 경우 Z3가 비정상 종료했다. 정해지지 않은 정렬은 증명(unsat)은 바로 끝내지만 한정자가 있는 만족 질의에서 모형 탐색이 자원 한도까지 간다(그 뒤 지상 인스턴스 재시도가 반례를 찾는다: 실패 하나에 5M을 쓴다).

조치(`verify::datatypes`): 재귀 구조체의 값은 `Int` 손잡이다(정렬 이름은 구조체의 것, `define-sort`). 필드는 선택자 함수, 값 만들기는 새 상수와 선택자 등식의 지상 사실(`Enc::mk_struct`), 필드의 범위·길이 사실은 의무의 경로 조건과 목표에 나오는 선택자 적용마다 지상으로 더한다(`Prog::struct_facts`, ADR-0056 §2). 생성자 함수와 한정자 공리가 없으므로 질의는 한정자 없이 남는다. 손잡이에 산술은 없어서 `Int`는 정렬의 원소 수 말고는 의미를 바꾸지 않고, 인코딩은 원소 수에 기대지 않는다. 구조적 감소는 2O-03c와 같은 선택자 사슬(구조체 생성자는 판별자 없음)이고, 그것이 엄격한 부분인 것은 프로그램 값이 유한하다는 데서 온다.

재현: `z3 struct-datatype.smt2`(걸림), `z3 struct-sort.smt2`(`unknown`), `z3 struct-int.smt2`(`sat`).
