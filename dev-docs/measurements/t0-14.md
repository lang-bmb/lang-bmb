## 읽기

- **작성 하락폭:** 알파 −24%p(23 → 17), 오도 −8%p(23 → 21). 둘 다 D = 30%p(ADR-0077 §4) 안이라 방향을 주장하지 않는다.
- **탐색은 그대로**(12/12 셋 모두). 호출자·영향 질의는 이름이 아니라 그래프로 답한다.
- **BSB 판별률**은 알파에서 93.5% → 59.1%로 크게 떨어졌다. 분모는 늘 186개 전부이고 계약이 없는 작업 공간은 하나도 죽이지 못하므로(`harness.spec_kill`), 작성 실패가 늘면 판별률도 함께 떨어진다. 계약의 강도가 약해졌는지 작성 실패 몫인지는 이 표만으로 가르지 않는다.
- **비용:** 알파는 입력 토큰 +55%, 한도 도달 2 → 6. 이름이 사라지면 모델이 정의를 더 많이 읽는다.
- **H-NAME 판정:** 가설은 "난독화 하락폭이 Rust+테스트보다 작다"이고 Rust 쪽 쌍둥이(T1-04의 남은 것)가 없어 비교 절은 판정할 수 없다. 이 실행은 BMB 쪽 하락폭의 정식 값이다. 파일럿(큰 모델, 37/37 유지)과 달리 작은 모델에서는 알파판이 작성 6과제를 잃는다.
