# T2-17: 메모리 한도와 프로세스 재사용

> 2026-11-12 · 결정: ADR-0129 · Z3 4.15.4, 릴리스 빌드, 4코어 머신(측정 내내 다른 작업으로 부하 8~19: 시간은 CPU 초를 적고 벽시계는 참고)
> "앞"은 트리 `9938d706`의 `bmb`, "뒤"는 이 태스크의 변경을 넣은 `bmb`.
> 도구(커밋하지 않음): 질의마다 `check-sat` 시간·답·`rlimit`을 적는 `z3` 대리 스크립트, `bmb verify --emit-smt`의 스크립트를 질의로 쪼개 Z3에 직접 보내는 스크립트.

## (b) 탐침이 한도에서 끝난 뒤

- 재현: 탐침 몫의 `rlimit`(`Z3_RLIMIT / 100`)을 받은 질의에서 Z3처럼(종료 코드 101) 끝나는 가짜 해법기로 `tests/check/ok/search.bmb`를 검증. 앞: E0811(사유 메모리) 7개, 전체 질의는 묻지 않음. 뒤: 모두 증명.
- 시험: `gate.rs` `after_a_probe_at_the_memory_limit_the_query_is_asked`.

## (d) `lint --cache`

- 재현(앞): `requires x < 100, x < 1000`인 함수. 절 `x < 1000`을 뺀 프로그램을 `bmb verify --cache DIR`로 증명해 둔 뒤, 권고 한도에서는 바로 끝나는 가짜 해법기로 `bmb lint`: 캐시 없이 W0902 0개, `--cache DIR`로 W0902 1개(출력이 다름). 뒤: 둘 다 0개, 같은 바이트.
- `lib/std` 11파일의 `bmb lint`(파일마다 따로):

| 실행 | 출력 | CPU 초(합) |
| --- | --- | --- |
| 앞, 캐시 없음 | 기준 | 699 |
| 뒤, 캐시 없음 | 11파일 모두 앞과 같은 바이트 | 735 |
| 뒤, `--cache`(빈 디렉터리) | 11파일 모두 같은 바이트 | 736 |
| 뒤, `--cache`(채워진 뒤) | 11파일 모두 같은 바이트 | 660 |

- 시험: `compiler/tests/lint.rs` `a_cached_gate_proof_does_not_answer_an_advisory_query`.

## (e) `lib/std`의 `lint` 시간

앞, 대리 스크립트로 적은 질의 6,003개(`check-sat` 시간의 합 1,003초, 부하 아래. 대리 스크립트의 결함으로 메모리로 끝난 5개는 다른 오류로 읽혔다):

| 질의 | 답 | 수 | 초 | `rlimit` 최대 |
| --- | --- | --- | --- | --- |
| 권고, 전체 한도(5,000,000) | `unknown` | 403 | 889.9 | 한도 |
| 권고, 전체 한도 | `sat` | 512 | 54.5 | 4,914,150 |
| 권고, 전체 한도 | `unsat` | 1,601 | 4.1 | 256,942 |
| 권고, 탐침 몫(50,000) | `unknown` / `sat` / `unsat` | 508 / 382 / 717 | 12.1 / 2.5 / 1.9 | — |
| 권고, 도달 지점(1,000,000) | `unknown` / `sat` | 74 / 52 | 18.3 / 0.3 | — |
| 첫 검증(게이트), 전체 한도 | `unsat` | 1,220 | 3.9 | 485,775 |

- 시간의 89%가 전체 한도까지 가는 권고 질의 403개다(서로 다른 텍스트 394개). `bmb` 자신의 CPU는 잰 두 파일(`str`, `collections`)에서 0.6초, 0.5초다(전체 11.2초, 4.4초 중).
- 보고는 모두 `unsat`이 있어야 한다. 권고 질의의 `unsat` 1,601개는 모두 `rlimit` 256,942 아래다. 1,000,000을 넘겨 답한 권고 질의 11개는 모두 `sat`이다.
- 실험(뒤, `BMB_Z3_RLIMIT=1000000`: 게이트·탐침 몫도 함께 낮아지므로 권장안보다 넓게 낮춘 것): 11파일의 보고 줄이 모두 같고 CPU 735 → 230초. 요약의 `reach_undecided` 합은 68 → 103(탐침 몫이 50,000 → 10,000이 된 탓이 섞여 있다).

권장안(권고 질의의 전체 한도를 따로 두는 것)은 구현하지 않았다: `lint`가 보고하는 것을 바꿀 수 있는 결정이라 태스크 보고에 JUDGMENT §10 형식으로 올렸다.
